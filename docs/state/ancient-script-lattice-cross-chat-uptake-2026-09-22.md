## 1. Core research posture

Treat the Ancient Script Lattice as an evidence-constrained historical inference system rather than a resemblance engine.

Canonical evidence spine:

```
witness -> carrier -> exact form -> normalized reading -> language -> semantic address -> relation -> hypothesis
```

Preserve three distinct epistemic layers:

- **OBSERVATION** — what is actually present in an artifact, inscription, edition, photograph, lexical source, or securely reconstructed linguistic datum.
- **RELATION** — a typed connection between observations: inheritance, borrowing, translation, graphic adaptation, phonological development, spatial association, chronological succession, functional equivalence, etc.
- **HYPOTHESIS** — an explanatory model built from relations: migration, common ancestry, transmission route, decipherment, semantic development, symbolic continuity, or other higher-order reconstruction.

Never allow a hypothesis to migrate backward and masquerade as an observation.

Promotion ladder:

```
OBSERVED -> CANDIDATE -> TESTED -> CORROBORATED -> CANONICAL
```

Retain: FAILED, CONTRADICTED, SUPERSEDED, Ω-UNRESOLVED. Uncertainty is data.

## 2. Typed historical transformation

Canonical rule:

> Do not compare words or glyphs in isolation. Compare typed historical transformations and ask what survives them.

Useful state:

```
X = (C,F,R,L,T,K,P,Q)
```

Dimensions: carrier, exact form, role/function, location, time/phase, classifier/context, provenance, referent.

For each edge:

```
X_i --tau--> X_j
```

record operator type, evidence source, transformation cost, preserved invariants, losses, gains, and uncertainty/status.

Operators include inheritance, borrowing, translation, script adaptation, phonological change, semantic change, syncretism, exonym formation, title transfer, visual resemblance, functional equivalence, replacement, carrier erosion, and analogy. Never collapse these into generic similarity.

## 3. Evidence laundering control

A derived conclusion cannot return to the graph as an independent witness for the hypothesis that generated it. Several modern sources descending from one ancient lexical list, inscription, reconstruction, or edition may constitute one effective witness. Count independent ancestral/transmission nodes rather than modern descendants.

## 4. Physical artifact control

Physical substrate precedes sign interpretation:

```
artifact -> image state -> mark classification -> glyph geometry -> direction/orientation
-> spacing/segmentation -> sign identification -> phonology -> lexical/grammatical interpretation
```

Kaminia/Lemnian supplies the control that apparent punctuation-like gaps can arise from natural stone porosity. Distinguish intentional mark / substrate feature / damage / restoration / uncertain before linguistic assignment. Apply to Konar Sandal, Proto-Elamite, Linear A, and other dark corpora.

## 5. Carian adversarial control

Egyptian–Carian and Greek–Carian bilingual decipherment establish:

```
graphic similarity != phonetic identity
```

Visually familiar/Greek-like signs need not carry appearance-suggested values. Cross-script phonetic bridges based primarily on shape must outperform this false-equivalence control.

## 6. Lemnian / Tyrsenian calibration

Lemnian is a high-value calibration corpus. Preserve:
- Kaminia and related constrained inscriptional objects;
- boustrophedonic behavior;
- artifact-level segmentation/punctuation verification;
- Hephaistia as an independent phonological witness;
- heloke as relevant to Lemnian aspiration;
- Lemnian/Etruscan/Raetic correspondences tested through morphology, phonology, and syntax.

Keep separate:

```
language ancestry != script ancestry != population migration != material-culture transmission
```

A simple southern-Etruscan -> Lemnian alphabet derivation is weakened by differing local adaptations. Anatolian-origin/migration formulations are also weakened relative to earlier versions; dispersal direction remains a hypothesis requiring archaeological and chronological support.

## 7. Tyrsenian productive contradiction

Preserve the tension between linguistic proximity and absence of corresponding whole-culture archaeological transfer. Test limited migration, mercantile settlement, elite transfer, language transfer without wholesale replacement, earlier common dispersal, and multiple-stage contact. Do not automatically weaken linguistic evidence to erase the contradiction.

## 8. Linear Elamite chain

Preserve:

```
su2-h-te-r -> /sohter/ -> suhter ~ shuhter
```

Internal Elamite diachronic relation is stronger than downstream comparison with Greek soter. Keep:
- OBSERVATION: attested/read Elamite forms;
- RELATION: internal Elamite phonological/diachronic continuity;
- HYPOTHESIS: relationship with Greek σωτήρ.

Do not allow internal-edge strength to leak into the external comparison.

## 9. Konar Sandal chirality

Orientation/chirality remains Ω-UNRESOLVED. A single asymmetric sign cannot distinguish true boustrophedon, mirrored allography, scribal variation, damage, publication mirroring, photographic rotation, or modern manipulation.

Required corpus:
artifact orientation -> excavation/publication provenance -> line order -> asymmetric sign geometry -> stroke intersections -> mirror/rotation transforms.

Promotion requires multiple independent signs or objects agreeing under one directional model.

## 10. Sumerian formation controls

Visible segmentation does not establish native morphological composition. Some apparently segmentable forms may reflect Akkadian lexical material or other non-native structures.

```
visible segmentation != native morphological composition
```

Halloran-style Proto-Sumerian formation models remain hypothesis generators requiring strong nulls. Sound-symbolic/phememe structures remain HYP/HEUR unless independently demonstrated.

## 11. Contaminated lexical-source control

Mislabelled or linguistically contaminated “Sumerian dictionary” material should be retained as CTRL rather than discarded. Use it to test detection of language mislabeling, source contamination, lexical laundering, false equivalence, and inherited database errors.

## 12. Native Akkadian layer

Test native mechanisms before cross-language explanations: assimilation, cluster repair, weak-root behavior, aleph loss, vowel contraction, derivational stems, lexicalization.

```
root continuity != transparent semantic composition
```

Cross-language candidates must beat plausible language-internal derivation.

## 13. Numeral-carrier experiment

Strict seven carrier:

```
C7 = [SIBILANT] X* {p,b,f,phi,beta,w}
```

Count ancestral/transmission nodes, not modern daughters. Pilot across numerals 3–10 produced strict-carrier concentration at both 6 and 7; six is therefore a mandatory competitor.

Current state:
- OBSERVATION: 6 and 7 show unusual carrier concentration in the pilot.
- RELATION: several independent historical nodes show compatible carrier structures.
- HYPOTHESIS: seven preserves an unusually persistent cross-family phonological carrier.
- STATUS: CANDIDATE.

Next benchmark: numerals 1–10 under identical rules, using an enrichment statistic such as:

```
E(n) = observed carrier concentration / null expectation
```

with ancestry correction, reconstruction sensitivity, phonological admissibility, multiple-testing controls, and direct comparison with six.

## 14. Reconstruction sensitivity

Every proto-node must preserve:
reconstructed form -> source -> publication/date -> reconstruction method -> daughter reflexes -> regular sound laws -> uncertainty.

Source-lock Proto-Berber, Proto-Kartvelian, Proto-Uralic, and other inferentially important reconstructions before counting them as strong carrier witnesses.

## 15. QBL split

Separate:
- FRONT/FACE -> ENCOUNTER
- CENTER/MIDDLE.

Akkadian belongs primarily to the latter. Carrier convergence does not prove common etymology. Preserve observation, possible structural/interface relation, and common-origin hypothesis as separate layers.

## 16. False-Equivalence Control Suite

Required adversarial controls:
- Carian: graphic resemblance != phonetic identity
- Kaminia: apparent mark != intentional writing
- Sumerian/Akkadian: visible segmentation != native composition
- QBL: carrier convergence != common etymology
- Tyrsenian: language ancestry != script ancestry != migration direction
- Linear Elamite: strong internal continuity != strong external comparison

Every future cross-script candidate must state what it explains that these mechanisms cannot.

## 17. Interaction-information experiment

Experimental metric:

```
Delta_int(A,B) = H(A compose B) - F(H(A),H(B))
```

Use to distinguish juxtaposition from recoverable interaction structure. Treat as an experimental metric, not an evidential verdict.

## 18. Witness protocol

Dark/disputed corpora preserve competing readings as branches. Calibration types include textual-strata preservation, undeciphered-script structural inference, competing decipherments, metrology/geometry reconstruction, and restoration/transmission genealogy.

Independent discriminators, not pressure for graph simplicity, collapse branches.

## 19. Typed edge architecture

Maintain distinct edge families:
FORM, PHONOLOGY, SEMANTICS, GRAMMAR, CHRONOLOGY, SPACE, SCRIPT_DESCENT, LANGUAGE_DESCENT, BORROWING, TRANSLATION, POPULATION_MOVEMENT, MATERIAL_CULTURE, FUNCTION, SYMBOLIC_ANALOGY.

Strong edges do not automatically strengthen neighboring edge types.
