## 1. Typed Relation Vector

Canonical comparison object:

```
R(A,B) = <F,P,M,S,G,T,X,C,V>
```

F exact/formal sign correspondence; P phonological; M morphological; S semantic; G grammatical/syntactic; T chronological admissibility; X spatial/contact admissibility; C carrier/script compatibility; V provenance/witness independence.

Dimensions are not freely compensatory:
- high F does not license P;
- high P does not override T;
- high S is not genealogy;
- dependent witnesses do not multiply V.

## 2. Path-Specific Promotion

Promotion is relation-type specific, not an aggregate-score threshold.

- etymological/cognacy candidate: P + M + T + X + V
- exact-sign transmission: F + C + T + X + V
- translation equivalence: S + G + T + V
- borrowing/contact: P/M and/or S + T + X + V
- graphic inheritance: F + C + T + X + V
- structural analogy: relevant structural dimensions + null control; no automatic genealogy

Missing mandatory dimensions impose a confidence ceiling.

## 3. Canonical Witness Separation

```
WITNESS
```

No downstream normalization overwrites its source-facing witness.

## 4. General Carrier/Readout Law

```
CARRIER != READING != LANGUAGE != SEMANTIC ADDRESS
```

A surviving sign does not automatically preserve earlier pronunciation, source language, grammatical function, or semantic address.

Principal positive control: Hittite heterograms.

## 5. Comparison Ladder

```
exact sign
-> allograph
-> normalized sign
-> phonological realization
-> historically relaxed form
-> diachronic reconstruction
```

Every movement between levels is an explicit operator. Visual resemblance may not silently become phonetic identity.

## 6. Dependency Graph / Independence Correction

```
CLAIM = result + parents + transform + confidence ceiling
```

Supporting routes count as independent only when dependency graphs are sufficiently disjoint. Daughter languages sharing one reconstructed ancestor are not independent witnesses; editions of one ancient source are not independent primary witnesses.

This is the formal anti-evidence-laundering mechanism.

Failures remain corpus evidence. Unknown is information.

## 13. Relation != Genealogy

A relation may be historically meaningful without being genealogical.

Typed edges include inheritance, borrowing, translation, transliteration, readout transposition, semantic substitution, syncretism, recension, custody, substrate, language shift, title transfer, functional equivalence, graphic convergence, structural analogy, population movement, and shared scribal matrix.

No edge silently upgrades into ancestry.

## 14. Historical Object Definition

```
HISTORICAL OBJECT =
transportable state across multiple partially independent channels
```

Channels may include sign, sound, morphology, semantic address, operator sequence, position, audience, institutional identity, spatial address, and residue.

A historical object need not preserve every channel simultaneously.

This supersedes the untyped question "Is X the same as Y?" in HOME/VAULT methodology.
