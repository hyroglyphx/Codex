## Purpose

Promote a small source-locked Sumerian control set whose native morphology cleanly separates holder, office, function, statement, name, witness, and ordered/right state.

This is a calibration set, not a claim of direct transmission into every comparison domain.

## 1. Holder versus office

```
LUGAL = king / holder
NAM-LUGAL = kingship / office-state
```

Canonical distinction:

```
HOLDER
!=
OFFICE
```

The relation between a person/entity and an office is typed rather than lexicalized as identity.

## 2. NAM as abstraction/state operator

NAM forms state/office abstractions in compounds.

Use as a positive morphological control for:

```
ENTITY
-> ABSTRACT_STATE
ENTITY
-> OFFICE
ENTITY
-> STATUS
```

without assuming equivalent morphology in another language.

## 3. ME as function/office/capacity

The recovered lexical envelope includes:
- function;
- office;
- responsibility;
- ideal norm;
- divine/cultic capacity;
- decree/oracle in some contexts.

Do not compress ME to one mystical gloss.

This is especially useful for identity systems in which:
- entity;
- name;
- office;
- function;
- authority

are separable coordinates.

## 4. ME-NAM-NUN-NA

```
ME

```

The exact translation remains source-sensitive.

## 5. INIM versus MU

```
INIM
=
word / statement / matter
```

```
MU
=
name / word / year / line-entry / oath
and naming-speaking in verbal use
```

Do not collapse:
- NAME;
- STATEMENT;
- OATH;
- SPEECH;
- RECORD ENTRY.

The overlapping semantic fields are historically real but type-distinct.

## 6. Witness as statement-bearing role

```
LÚ-INIM-MA
=
witness
```

with morphology centered on person + statement.

```
LÚ-KI-INIM-MA
```

adds a place/context relation.

Use this as a legal-role control:

```
PERSON
+ STATEMENT
+ CONTEXT
-> WITNESS_ROLE
```

## 7. Straightness -> order -> rightness

```
SI-SÁ
```

has a lexical range including:
- straight/right;
- make straight;
- put in order;
- do correctly;
- legal/fair uses.

```
NÍ-SI-SÁ
```

supplies an equity/justice control in the recovered list.

This is a native semantic-path example:

```
PHYSICAL_ALIGNMENT
-> ORDER
-> CORRECTNESS
-> LEGAL_RIGHTNESS
```

Use it as PHASESHIFT/semantic-extension calibration, not as proof of cross-cultural etymology.

## 10. Cross-application to name/speech systems

The INIM/MU split provides a negative control against treating:
- naming;
- speaking;
- legal declaration;
- oath;
- textual entry

as one universal operator.

## Governing rule

> Native morphology that separates holder, office, function, name, statement, witness, and right-order should be used as a calibration against identity flattening elsewhere.
