# Dual-Use Carrier and Protective-Gloss Protocol v0.1

Status: ACTIVE_EXPERIMENTAL
Date: 2026-09-22

## Purpose
Extend Codex/Structural Continuation to systems whose historical surface vocabulary may not exhaust their operational structure.

Core separation:

```
SURFACE CLASSIFIER != OPERATIONAL SUBSTRATE
DECLARED FUNCTION != EXHAUSTIVE FUNCTION
```

This protocol does not infer hidden intent from labels. It asks what operations are recoverable from the surviving carrier and whether those operations persist when historical labels are removed.

## State extension

```
X = (carrier, surface, operator, state, path, invariant, provenance)
```

Add:
- surface: historical/self-described classifier and vocabulary
- operator: mechanically recoverable transformation(s)
- disclosure_state: explicit / indirect / absent / unknown
- dual_use_candidate: whether more than one demonstrable function is supported

## Transformation class
`SEMANTIC_OBSCURATION_WITH_STRUCTURAL_PRESERVATION`

Candidate condition: semantic/readout visibility changes while a recoverable procedure, relation graph, ordering, geometry, or transformation grammar survives.

Absence of explicit disclosure is not by itself a falsifier when concealment/limited disclosure is part of the tested functional hypothesis. The hypothesis must instead earn support through operational recovery, contemporary controls, provenance, and holdout behavior.

## Label-Blind Operational Recovery
Run two parsers:

A. historical parser: receives native vocabulary and context.
B. operational parser: receives only carrier geometry, symbols, ordering, transformations, recurrence, numeric assignments, and reading procedures.

Compare:

```
I_labelblind(X) = Parse_A(X) intersect Parse_B(X)
```

Surviving structure is a candidate operational invariant.

### Adversarial inversion
Describe an unquestionably mathematical control object using historically plausible metaphorical vocabulary. A robust parser should recover its operator structure rather than classify by rhetoric.

## Dee laboratory
John Dee is the first benchmark because the corpus places explicit mathematical work (astronomical geometry, Euclid, parallax, navigation, calendrics) beside Monas/angelic-table material and a pre-Dee alphabet/steganography context.

Benchmarks:
- DEE-01 Monas compression/decomposition
- DEE-02 table combinatorics
- DEE-03 directed reading/reversal
- DEE-04 pre-Dee transformation graph: Trithemius/Agrippa/Pantheo -> Dee, with typed edges only
- DEE-05 Propaedeumata -> Monas operator comparison
- DEE-06 Euclidean mathematical control
- DEE-07 parallax/projection/inversion control
- DEE-08 contemporary steganographic control
- DEE-09 label-blind classification and adversarial inversion

## Promotion rule
Do not promote a concealed-function hypothesis from suggestive vocabulary, biography, resemblance, or absence of disclosure. Promote only a recovered operation that:
1. is specified independently of the interpretive label,
2. is reproducible from the carrier,
3. survives at least one relevant control,
4. preserves provenance,
5. makes a discriminating prediction or survives holdout where possible.

## Integration
This protocol feeds Structural Continuation by treating surface vocabulary as one representation layer. It feeds TCIM by separating carrier, classifier, role/function, phase, and provenance. It feeds Organon by adding label-blind traversal and dual-use-function tests.
