# Elamite / Linear Elamite Carrier-Pivot Calibration v0.1

Status: CANONICAL_CALIBRATION_PROTOCOL  
Date: 2026-09-22  
Program: Ancient Script Lattice / ECVR / TCIM / Linguistic Core

## Purpose

Promote Elamite and Linear Elamite to the flagship **Carrier-Pivot Calibration** corpus.

The calibration asks what remains invariant when an identifiable linguistic system is observed through different writing systems, orientations, scribal conventions, historical phases, and multilingual administrative environments.

## Governing separations

```
LANGUAGE CONTINUITY != SCRIPT CONTINUITY
SCRIPT SUCCESSION != LANGUAGE DESCENT
ORIENTATION CHANGE != LINGUISTIC CHANGE
INTERNAL DIACHRONIC SUPPORT != EXTERNAL ETYMOLOGICAL SUPPORT
GEOGRAPHIC/CHRONOLOGICAL SUCCESSION != PROVED DESCENT
ADMINISTRATIVE CONTINUITY != LANGUAGE CONTINUITY
```

Proto-Elamite -> Linear Elamite remains Ω-UNRESOLVED unless independently demonstrated.

The 2022 Desset–Tabibzadeh–Kervran–Basello–Marchesi decipherment proposal is treated as an explicit scholarly model to test and calibrate, not as a license to erase competing readings.
