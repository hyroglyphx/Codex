# Invariant Ecology Registry (IER)

IER is the standing normalization grammar for new constructs.

## Canonical tuple

```text
X = (O, P, R, A, I, T, C, G)
```

| Symbol | Field | Question |
|---|---|---|
| O | Object | What is being studied? |
| P | Partition | How is it decomposed or scoped? |
| R | Representation | In what encoding, geometry, language, or state-space is it expressed? |
| A | Admissible Operations | Which transformations are allowed? |
| I | Invariant | What survives those transformations? |
| T | Attractor | What stable/recurrent state or class appears? |
| C | Compression | What minimal signature retains the relevant structure? |
| G | Regeneration | Can the object/result be reconstructed, replayed, or retested from the compressed state? |

## Registry rule

No new cross-domain construct is promoted solely because two representations look similar.

A candidate bridge should declare:

1. source objects,
2. representations on both sides,
3. admissible transformations,
4. proposed invariant,
5. negative/adversarial controls,
6. regeneration or return test,
7. provenance and authority,
8. maturity state.

## Admissible transport

For state space (X) and admissible map family (A):

```text
x_(n+1) ∈ A(x_n)
```

A transport claim is stronger when the return path is explicit and the resulting invariant can be independently regenerated.

## Example: numeral-seven carrier

Recovered strict carrier:

```text
C7 = [SIBILANT] X* {p,b,f,φ,β,w}
```

Keep the broader m-inclusive variant separate; do not silently widen the strict carrier.

Mandatory adversarial controls include:
- Sumerian *imin* — carrier failure,
- Hurrian — partial carrier,
- Etruscan six *huθ* — break against a generalized six/seven sibilant hypothesis,
- Armenian — inherited seven may become surface-opaque,
- Albanian/Turoyo *tre* — surface-collision control.

This example illustrates the intended IER behavior: preserve successes, partials, and failures in one object ecology rather than optimizing only for matching cases.
