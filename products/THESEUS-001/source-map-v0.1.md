## Source lock

Primary internal source: `The Theseus Cycle — Mathematics, Language, and Logic: Tokens, Paths, Labyrinths, and the Architecture of Civic Identity` (73-page omnibus).

Source discipline inherited from omnibus:

- REF = historical/narrative claims grounded in named ancient witnesses.
- FORM = declared modern formalization.
- ANA = declared transport/analogy.
- HEUR = generative extension requiring independent testing.
- Preserve source variation; do not retroject modern mathematics into ancient authors.

Canonical completion grammar:

Carrier → Objects → Operators → Constraints → Invariants → Residues → Certificates → Boundaries

Rosetta transport grammar:

C = (T, I, R, B)

where T = transport map, I = preserved invariant, R = surviving residue, B = stopping boundary.

Identity state used in the terminal lab:

I(t) = (M, F, P, R, H, A, L)

material, function, provenance, relations, history/memory, agency, legitimacy.

## Why 12 public encounters

The source contains 23 operators. The paid Field Lab will not erase the other eleven. Twelve are selected because together they reconstruct the complete identity curriculum while maximizing exercise diversity and avoiding repeated mechanics.

The remaining operators live in the reference omnibus, card expansions, audio episodes, web nodes and future advanced labs.

## Public encounter set

### 01 — The Hidden Claim
Source chapters: 1 + support from 10.
Operator: delayed identity / recognition under adversarial framing.
Invariant: a claim may be true before it is publicly provable.
Lab action: construct a time-separated proof packet; distinguish claimant, evidence, recognizer and recognition time.
Adversary: resemblance-only recognition; premature public claim.
Primary artifact: authentication timeline / sealed-claim worksheet.

### 02 — Sword & Sandals
Source chapter: 2.
Operator: embodied authentication.
Invariant: provenance is relational, not visual resemblance.
Lab action: authenticate competing claimants using artifact + provenance + location + retrieval + recognizer.
Adversary: counterfeit resemblance and possession without provenance.
Primary artifact: provenance card + authentication puzzle.

### 03 — The Dangerous Road
Source chapters: 3–8 compressed as one route laboratory, with Periphetes retained as a nested capability-capture case.
Operator: route selection as public proof.
Invariant: the path changes the traveler even when endpoint is unchanged.
Lab action: choose between routes under cost, risk, proof yield and public benefit; compare arrival states.
Adversary: danger for its own sake / risk theater.
Primary artifact: route board + state ledger.

### 04 — Sinis / Stored Energy
Source chapter: 5.
Operator: stored-energy reversal.
Invariant: visible action may be downstream of latent system tension.
Lab action: trace input, stored potential, release trigger and delayed consequence.
Adversary: treating reversal as automatic justice.
Primary artifact: tension-release tracing board.

### 05 — Procrustes
Source chapter: 9.
Operator: destructive normalization / metric violence.
Invariant: typed variation can be destroyed by preserving the standard at all costs.
Lab action: normalize a mixed dataset under competing standards and record information loss.
Adversary: confusing comparability with legitimacy.
Primary artifact: normalization board + before/after evidence sheet.

### 06 — Tribute, Labyrinth & Minotaur
Source chapters: 12–14.
Operator: periodic extraction + constrained search + containment without resolution.
Invariant: local containment can preserve the system that generates hidden residue.
Lab action: model tribute inflow, maze state-space and hidden institutional residue; distinguish target removal from system repair.
Adversary: declaring victory because the contained target is removed.
Primary artifact: labyrinth tracing board + extraction-flow diagram.

### 07 — Ariadne's Thread
Source chapters: 13 + 15.
Operator: external path memory + assistance debt.
Invariant: successful inward search is incomplete without recoverable exit information; outcome equivalence does not erase path-dependent obligation.
Lab action: solve a maze with and without externalized traversal memory; reconstruct return path; then audit relational residue.
Adversary: assuming one successful path maps the whole labyrinth; ignoring the enabling relationship.
Primary artifact: reversible maze + path-memory ledger.

### 08 — The Black Sail
Source chapter: 16.
Operator: state-report failure.
Invariant: actual state and reported state must be modeled separately.
Lab action: propagate a stale state symbol through a receiver that acts irreversibly; introduce verification delay and compare outcomes.
Adversary: assuming sender success guarantees system success.
Primary artifact: signal-state diagram / communication experiment.

### 09 — Synoecism / The Civic Vessel
Source chapters: 17–18.
Operator: federated unification + institutional embodiment.
Invariant: common identity can emerge without deleting every local relation.
Lab action: merge multiple local systems into a shared decision frame while preserving selected local invariants.
Adversary: civic Procrustes — unity by erasure.
Primary artifact: federation map / governance board.

### 10 — Oath Capture
Source chapters: 19–20.
Operator: mutual-capability coupling → oath capture/domain violation.
Invariant: loyalty remains ethical only while future objectives remain independently reviewable.
Lab action: draft an alliance contract with scope, veto and exit; test an inadmissible later objective.
Adversary: prior promise treated as universal authorization.
Primary artifact: oath/admissibility card set.

### 11 — The Tablet, Judgment & Founder Separation
Source chapters: 21–22.
Operator: irreversible judgment under asymmetric evidence → founder-system separation.
Invariant: stronger irreversibility requires stronger verification; founder, institution and founder-memory are separable objects.
Lab action: run a testimony cascade, then a founder-removal simulation; compare truth recovery with state recovery.
Adversary: unaudited testimony; assumption that institution equals founder.
Primary artifact: evidence-threshold worksheet + founder-ablation board.

### 12 — Ship of Theseus Identity Atlas
Source chapter: 23 + whole-cycle synthesis.
Operator: multi-channel continuity under replacement.
Invariant: identity under replacement is a typed family of continuities, not a universal scalar.
Lab action: score changing scenarios across M,F,P,R,H,A,L; change evaluator weights; compare typed answers.
Adversary: answering 'same' before declaring the identity predicate.
Primary artifact: seven-axis identity instrument + scenario cards.
