# Sumerian–Akkadian–Hurro-Urartian Confidence Corridor v0.1

**Date:** 2026-09-25  
**Status:** ACTIVE / EDGE-TYPED FIRST PASS

## Core idea

Do not ask for one undifferentiated relationship among Sumerian, Akkadian, Hurrian and Urartian.

Build a corridor from several independently strong edges:

```text
SUMERIAN --scribal/lexical--> AKKADIAN --scribal/institutional--> URARTIAN
                                  \
                                   \ contact / cultural vocabulary
                                    -> HURRIAN <==genetic==> URARTIAN
```

The corridor becomes stronger when multiple relation types converge on the same historical zone without being collapsed into one ancestry claim.

## 1. Backbone A — Sumerian -> Akkadian cuneiform/lexical continuity

High-confidence controls:
- cuneiform was first developed for Sumerian and then adapted for Akkadian;
- Sumerian-Akkadian lexical lists explicitly map Sumerian forms to Akkadian readings;
- `LUGAL = šarrum` is directly attested in lexical tradition;
- Sumerian logograms remained productive inside Akkadian texts into the first millennium BCE.

Operational status:

```text
CARRIER / LEXICAL TRANSMISSION = A
GENETIC RELATION = none proposed
```

## 2. Backbone B — Akkadian/Assyrian -> Urartian scribal transition

Urartu supplies a near-controlled historical handoff:

```text
Sarduri I:
Neo-Assyrian language + Neo-Assyrian cuneiform

Išpuini / Minua onward:
Urartian language + adapted Neo-Assyrian cuneiform
```

The Kal-e Šīn stele is bilingual Assyrian-Urartian.

Early Urartian royal formulae closely follow Neo-Assyrian titulary. Sarduri I's Akkadian inscription uses the inherited royal formula and later Urartian inscriptions retain Mesopotamian logograms within Urartian syntax and morphology.

Examples retained in eCUT:

```text
LUGAL / MAN = king
KUR = land/country classifier
URU = city classifier
DINGIR = god-classifier/logogram
ÍD = river
```

and native Urartian lexemes coexist with them:

```text
ebani = land / territory
patari = city
pili = canal
nun- = come
```

Operational status:

```text
SCRIPT / FORMULA / INSTITUTIONAL TRANSMISSION = A
LEXICAL BORROWING = item-specific
GENETIC RELATION = none
```

## 3. Backbone C — Hurrian <-> Urartian genetic relation

This is the only secure genetic edge in the corridor.

Urartian is a cognate of Hurrian and is especially close to Old Hurrian. Shared morphology includes ergative alignment, related plural/case morphology and reconstructable phonological correspondences.

Operational status:

```text
GENETIC = A
PROTO-HURRO-URARTIAN RECONSTRUCTION = active but incomplete in-house
```

## 4. Bridge D — Akkadian as mediator into Hurrian

The historical record contains strong evidence for Akkadian-Hurrian lexical and scribal contact.

Examples worth treating as bridge candidates:

```text
Akkadian ḫasīsu 'ear / understanding / wisdom'
-> Hurrian ḫazizi / hazizi-type forms

Akkadian compounds and divine vocabulary
-> Hurrian cultic compounds
```

Kassian additionally notes that Hurrian cultural terms of Sumerian origin cited in earlier scholarship appear to have passed through Akkadian.

Therefore the corridor does not require direct Sumerian-Hurrian borrowing:

```text
SUMERIAN
-> AKKADIAN SCRIBAL / CULTURAL MEDIATION
-> HURRIAN
<-> URARTIAN
```

This is a stronger historical pathway than a naked Sumerian-Hurrian similarity.

## 5. Bridge E — direct Sumerian / Hurro-Urartian lexical probes

Alexei Kassian's 2014 test is useful as a candidate lane, not as the backbone.

He isolates five or six unusually close basic-vocabulary matches in a 65-item comparison and reports permutation-test probabilities ranging from about 6.9% in the roughest treatment to about 0.36% in the most restrictive treatment.

Most relevant triadic probe:

```text
Sumerian šu 'hand'
Hurrian šu-ni / su-ni 'hand'
Urartian su- 'hand'
```

This is currently the cleanest lexical candidate that actually touches Sumerian + Hurrian + Urartian.

Second probe:

```text
Sumerian ŋen 'go/come'
Urartian nun- 'come'
Hurrian un- 'come'
```

but the Hurrian-Urartian internal derivation is uncertain, so this remains weaker.

Kassian argues that simple late borrowing and a direct Sumerian-Hurro-Urartian genetic relationship are both problematic; he treats prehistoric language shift as a possible scenario. This must remain a hypothesis object, not a promoted lineage.

Operational status:

```text
FORMAL / SEMANTIC MATCH = C
DIRECT BORROWING = D
GENETIC UNITY = D/E
LANGUAGE-SHIFT RESIDUE = CANDIDATE
```

## 6. Bridge F — metalworking may preserve very early contact

A recurrent older proposal connects Hurrian `tabiri` 'caster/coppersmith' with Sumerian `tibira/tabira` 'metalworker/sculptor'.

This is notable because it moves in the opposite direction from the Sumerian->Akkadian scribal corridor and, if valid, may preserve a prehistoric craft-contact edge.

Do not use it as proof of ancestry.

## 7. The strongest confidence corridor

Current best path:

```text
SUMERIAN
  | explicit lexical/sign equations
  v
AKKADIAN / ASSYRIAN
  | explicit script + royal-formula transmission
  v
URARTIAN
  ^
  || secure genetic relation
  ||
HURRIAN
```

with a second diagonal:

```text
AKKADIAN -> HURRIAN
```

for cultic, lexical and scribal mediation.

The weakest edge is therefore not Urartian. It is the proposed prehistoric Sumerian <-> Hurro-Urartian lexical residue.

## 8. Highest-yield next tests

1. Track `LUGAL`, `KUR`, `URU`, `DINGIR`, `ÍD` from Sumerian lexical value -> Akkadian readout -> Urartian deployment.
2. Align Sarduri I's Akkadian titulary with Išpuini/Minua and Sarduri II Urartian titulary slot-by-slot.
3. Build a clause-level Kal-e Šīn Assyrian-Urartian alignment.
4. Build a Hurrian-Urartian cognate table with only secure morphology/basic lexicon.
5. Retest `šu / su- 'hand'` under a preregistered phonological null using only independently reconstructed forms.
6. Keep `ŋen / un / nun` as an adversarial secondary probe.
7. Search the Hurrian cultic lexicon for demonstrable Sumerian-origin terms mediated by Akkadian and require an Akkadian intermediate witness.
