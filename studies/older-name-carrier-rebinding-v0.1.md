# Older Name Carriers and Later Narrative Rebinding v0.1

**Date:** 2026-09-24  
**Status:** ACTIVE / FIRST SOURCE-LOCK  
**Scope:** Cambyses/Kambujiya, Deukalion, dynastic name reuse, cross-script carrier orbits, local royal titulary, mythic role rebinding

## Research question

When an ancient name survives across languages or centuries, how do we distinguish:

```text
NAME CARRIER
ENTITY
DYNASTIC REUSE
OFFICE
LOCAL ROYAL TITLE
NARRATIVE ROLE
MYTHIC GENEALOGY
LATER ETYMOLOGICAL ATTRACTION
```

The current Codex rule is retained:

```text
NAME CONTINUITY != ROLE CONTINUITY
```

This pass adds two unusually strong calibrators.

## 1. Cambyses / Kambujiya — cross-script royal carrier

Secure carrier orbit:

```text
Old Persian: Kambujiya
Elamite: Kanbuziya
Babylonian: Kambuziya
Greek: Kambyses
Aramaic: Kanbuzi-type forms
```

Behistun is the strongest control because the same historical figure is represented within a deliberately multilingual imperial monument.

The carrier is stable enough to identify the person while each writing-language naturalizes the readout.

### 1.1 Etymology remains unresolved

Modern scholarship preserves several competing analyses:

- possible relation to Old Indian Kamboja;
- possible Indo-Iranian compound analyses;
- older proposals of Elamite origin;
- proposed meanings including "king at will", "bringer of joy", "unshaken/intrepid", and others.

Therefore:

```text
strong carrier identity
!=
secure lexical decomposition
```

Cambyses is a useful negative control against deriving office or function from a visually attractive substring such as CAM-/KAM- without independent evidence.

### 1.2 Dynastic reuse

The name belongs to more than one Achaemenid royal bearer, including Cambyses I and Cambyses II.

Therefore:

```text
same royal name
!=
same narrative episode
```

Dynastic recurrence itself can be an identity operator.

Add:

```text
NAME-02 = DYNASTIC_CARRIER_REUSE
```

### 1.3 Egyptian re-encoding: same person, new sacral-office name

Udjahorresnet's Egyptian inscription claims that he composed Cambyses' Egyptian royal titulary, including the throne name:

```text
Mesutire / Mswty-Ra
```

interpreted in scholarship as "Offspring/Image of Re" within Egyptian royal ideology.

This gives an explicit transform:

```text
KAMBUJIYA
personal/dynastic carrier

-> conquest / new jurisdiction

KING OF UPPER AND LOWER EGYPT
office

-> MESUTIRE
local sacral royal classifier
```

The original Persian name does not disappear. A new culturally valid royal identity is superimposed on the same person.

This is a positive control for:

```text
TRN-02 = LOCAL_SOVEREIGNTY_RENAMING
```

and for the identity tensor:

```text
ENTITY stable
REFERENCE_FRAME changes
JURISDICTION changes
OFFICE changes
CULT_ADDRESS changes
ROYAL_NAME changes
```

## 2. Deukalion — Bronze Age name before the classical flood persona

Mycenaean Greek preserves:

```text
de-u-ka-ri-jo
= Deukalion
PY An 654.12
```

The bearer on the Pylos tablet is an officer/member of a military unit, not a literary flood survivor.

This is a major calibration point:

```text
NAME CARRIER attested in Bronze Age administration
-> centuries later
MYTHIC FLOOD / GENEALOGICAL ROLE
```

Therefore the later myth cannot be assumed to have invented the name from the flood function.

Add:

```text
NAME-03 = PREEXISTING_NAME_TO_MYTHIC_ROLE_REBINDING
```

### 2.1 The name is not exclusive to one mythical entity

Greek epic uses Deukalion for more than one heroic figure, including:

- Deukalion in the Cretan/Idomeneus genealogy;
- a Trojan warrior named Deukalion.

Thus:

```text
DEUKALION carrier
-> multiple entities
-> multiple roles
```

before or alongside its later concentration in the famous flood genealogy.

### 2.2 Later genealogy turns the name into a civilizational compression node

Apollodorus has:

```text
Deukalion + Pyrrha
-> Hellen
-> Dorus / Xuthus / Aeolus
-> Dorians / Ionians+Achaeans / Aeolians
```

The same narrative also uses the `laas` "stone" / `laos` "people" wordplay for the recreated population.

This is two compression mechanisms operating together:

```text
PERSONAL NAME
-> GENEALOGICAL ANCESTOR
-> ETHNIC MACRO-CLASSIFIER
```

and

```text
PHONETIC WORDPLAY
-> ANTHROPOGONIC STORY
```

### 2.3 Etymology should remain layered

Proposed explanations of Deukalion differ. Scholarship has connected the name with:

- a reconstructed `*deuk-` "care/consider" field;
- a proposed `*deu-k-` "shine/see" root;
- variants suggesting comparison with `Leukalion`;
- later popular attraction to wet/flood vocabulary.

Because the Mycenaean personal name predates the surviving full flood narrative, any flood-compatible etymology must be tested as:

```text
historical origin?
or
later semantic attraction?
```

not assumed.

## 3. Cambyses and Deukalion as complementary controls


## Governing rule

> A name may survive longer than the story attached to it.

> A ruler may acquire a new culturally valid name without ceasing to bear the older one.

> Myth can inherit an old name and then build a new semantic identity around it.
