## Source character

The supplied source is a narrative transcript built largely from Roman and later written traditions. It is useful for mapping historical transitions, but it is not a native Suebian language corpus.

Therefore the lane begins as:

```text
Roman witness / later chronicle
→ ethnographic description
→ migration/state transition
→ assimilation/custody
```

not as a direct lexical reconstruction.

## Research value

### 1. Confederation identity
The Suebi are treated as a broad Germanic confederational identity rather than a single permanently unified polity.

This is useful for the project's identity-transposition work:

```text
ethnonym
→ confederation
→ branch groups
→ migrating subset
→ territorial kingdom
→ assimilated regional legacy
```

### 2. Source-filter problem
The transcript explicitly notes the absence of an early native written Suebian language and the dependence on Roman observation.

This makes the Suebi a strong control for:

```text
observed culture
≠
observer's category
≠
native self-description
```

### 3. Migration / polity transformation
The source traces:
- Rhine/Elbe-associated Germanic confederational identity,
- Roman confrontation,
- migration into Iberia,
- settlement in Gallaecia,
- reuse of Roman administrative infrastructure,
- dynastic/religious change,
- eventual Visigothic absorption.

This is a historical **carrier-custody and institutional inheritance** case.

### 4. Language-status caution
Because the source does not provide a native inscriptional corpus, claims about:
- exact Suebian phonology,
- specific place-name etymologies,
- direct lexical continuity into Galician/Portuguese,
- internal dialect boundaries

remain unpromoted until independently witnessed.
