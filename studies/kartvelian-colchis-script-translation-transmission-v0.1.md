**Date:** 2026-09-23

**Scope:** Colchis, Kartli/Iberia, Kartvelian genealogy, foreign-script epigraphy, early Georgian textual transmission  
**Evidence spine:** WITNESS → TYPE → ADMIT → TEST → EXPLAIN → RETURN

## Research question

How much of the ancient Colchian/Kartvelian linguistic field can be recovered when the spoken substrate, inscription language, script, translation channel, and later daughter-language evidence are kept as separate typed coordinates?

## Core separation rule

> **spoken language != inscription language != script != semantic address**

This node upgrades Kartvelian from a distant external control into an active historical-language study. It does **not** infer a lost “Colchian alphabet.” Instead it tracks Kartvelian speech beneath Greek, Aramaic/Armazian, Iranian, Armenian, and later Georgian written interfaces.

## 1. Kartvelian genealogical frame

The extant Kartvelian (South Caucasian) family consists of:

- Georgian
- Svan
- Mingrelian / Megrelian
- Laz

The standard family model places Svan as the earliest-diverging extant branch, with Georgian and Zan forming the other major clade; Zan then comprises Mingrelian and Laz.

For ancient Colchis, the strongest current historical-linguistic model is **not** “Colchian = directly attested Zan.” Rather:

- the ethnic composition of Colchis was mixed/unclear;
- first-millennium BCE predominant speech is plausibly Kartvelian;
- scholarship often identifies the relevant dialect field as probable forerunners of later Zan;
- this remains a reconstructed substrate hypothesis rather than a directly written Colchian-language corpus.

### Admitted relation

```text
Proto-Kartvelian
├── Svan
└── Proto-Karto-Zan
    ├── Georgian
    └── Zan
        ├── Mingrelian
        └── Laz
```

**Status:** genealogical family structure = strong; exact dating/localization of prehistoric splits = model-dependent.

## 2. Colchis: probable Kartvelian speech under a Greek epigraphic interface

Vani provides a decisive carrier/readout control. The site is a major Colchian center with occupation from the 8th to 1st centuries BCE and evidence of Mediterranean and Middle Eastern interaction, including a long Greek bronze inscription.

What this permits:

- Greek literacy in a Colchian center is directly evidenced.
- A Kartvelian/Zan-like spoken substrate is historically plausible for the region.
- The Greek inscription does **not** itself prove the language spoken by the local population.
- Greek epigraphy therefore functions as an interface witness, not a substitute for a lost Colchian-language text.

### Invariant

```text
LOCAL POPULATION / REFERENT
        ↓
spoken substrate (candidate Kartvelian/Zan)
        ↓
foreign written interface (Greek)
```

The substrate must be recovered through convergent onomastic, comparative, archaeological, and contact evidence rather than by assigning Greek spelling directly to Kartvelian etymology.

## 3. Armazi bilingual: same-object parallel readout

At Armazi in ancient Iberia/Kartli—not Colchis—the second-century CE Stele of Serapeitis carries Greek and Aramaic texts on the same funerary object.

Important controls:

- the two texts substantially overlap but are not mechanically identical;
- the Aramaic side is longer and contains additional information;
- Greek and Aramaic therefore encode the same social referents with different discourse choices;
- the local Aramaic script tradition is conventionally called Armazian/Armazic.

### Classification warning

Modern reference works do not describe the non-Greek side identically. Georgian scholarship represented in the Georgian Encyclopedia identifies the language as Aramaic continuing the State/Imperial Aramaic tradition, while Encyclopaedia Iranica describes the famous tombstone as Greek and Middle Iranian written in an unusual Aramaic-derived script. This disagreement is preserved as evidence and must not be silently harmonized.

**Rule:** script classification and language classification remain separate fields.

## 4. Iranian title transport into Georgian

Iranian–Georgian contact is directly visible in administrative and lexical borrowing.

A key carrier is the high office/title represented by forms in the **bidaxš / pitiakhsh** orbit. Iranian, Aramaic-derived, Armenian, Greek, and Georgian representations demonstrate that:

- an institutional function can persist while phonetic realization changes;
- not every Iranian loan in Georgian passed through Armenian;
- Armenian mediation is a testable path and must be established item by item.

This is a high-value calibration object for:

```text
institutional invariant
→ script/readout shift
→ phonological accommodation
→ recipient-language morphology
```

## 5. Emergence of surviving Georgian epigraphy

The earliest surviving Georgian epigraphic monuments securely belong to the fifth century CE.

Current anchor set:

- Bir el Qutt, Palestine: Georgian mosaic inscriptions, conventionally dated to the 430s CE;
- Urbnisi: fifth-century material;
- Bolnisi Sioni: inscriptions conventionally dated around 493–503 CE.

These are witnesses for the **surviving written record**, not proof of the exact moment the Georgian alphabet was first created.

### Script sequence

```text
Asomtavruli / Mrgvlovani
        ↓
Nuskhuri
        ↓
Mkhedruli
```

The lineage is graphic/orthographic; it must not be confused with the deeper genealogy of the spoken Kartvelian languages.

## 6. Early Georgian translation strata

Early Georgian Christian literature is a translation/transmission field rather than a single-source pipeline.

The strongest working model is:

```text
Syriac roots
   ↓
mainly Armenian mediation
   ↓
early Georgian Christian literary strata
```

alongside increasingly direct:

```text
Greek → Georgian
```

The exact translation base varies by work/manuscript and must be established text by text. A Georgian construction may therefore preserve:

- native Georgian syntax,
- a Greek calque,
- Armenian mediation,
- an older Syriac layer,
- or later revision toward Greek.

This creates a strong multi-witness calibration lane for the Codex translation framework.

## 7. Three-witness Colchis/Kartvelian test

For every proposed ancient Colchian or Kartvelian etymology, require as many of the following as possible:

### Witness A — comparative Kartvelian
Georgian + Mingrelian + Laz + Svan, with regular correspondence rather than surface resemblance.

### Witness B — contemporary foreign transcription
Greek, Aramaic/Armazian, Iranian, Armenian, Latin, or another securely dated written form.

### Witness C — archaeological/geographical binding
The form is tied to a known person, office, river, settlement, tribe, cult, object, or route.

### Promotion rule

```text
A + B + C convergence
> A + B
> B + C
> isolated resemblance
```

No two-way resemblance is promoted to historical derivation without chronology, geography, and an admissible transformation path.

## 8. Epigraphic carrier matrix

Every new witness should record:

| Field | Required question |
|---|---|
| geographic locus | Colchis, Iberia/Kartli, Armenia, Pontus, Urartu, other? |
| date | when is the witness securely attested? |
| object | stele, coin, pottery, bronze, tomb, seal, manuscript? |
| script | Greek, Aramaic/Armazian, Georgian, Armenian, Latin, other? |
| written language | what language is actually encoded? |
| probable spoken substrate | Georgian-type, Zan-type, Iranian, mixed, unknown? |
| names/titles | Kartvelian, Iranian, Greek, Anatolian, uncertain? |
| parallel witness | is another language/version attached to the same object/referent? |
| translation type | literal, parallel, administrative equivalent, paraphrase, unknown? |
| phonetic transformation | what regular accommodations are visible? |
| semantic invariant | what function/referent survives across forms? |
| uncertainty | what competing explanation remains live? |
