## TIER A — immediate development value

### 1. AITHIOPES is a cosmographic classifier before it is a single fixed polity

Houston repeatedly treats "Ethiopian" as geographically expansive. The older Greek sources are more interesting than her synthesis.

**Homer, Odyssey 1.22–25**:
- Aithiopes are "farthest of men";
- divided in two;
- some at sunset;
- some at sunrise;
- Poseidon receives sacrifice among them.

**Iliad 1.423–425**:
- Zeus and the gods go to Ocean to feast with the "blameless Ethiopians."

**Herodotus 7.69–70** independently distinguishes:
- Ethiopians "above Egypt";
- "Ethiopians of the east / Asia" serving with Indians;
- distinguishes the two by speech and hair.

This is a major classifier result:

```
AITHIOPES
= context-sensitive Greek macro-classifier
  [African / Upper-Nile]
  [eastern / Asian]
  [cosmographic solar-edge]
```

### 7. Karabel is an exceptional layered-reidentification object

Houston's Memnon/Sesostris/Ethiopia lane leads to Herodotus 2.106.

Herodotus personally sees a western Anatolian rock relief on the Sardis-Smyrna road and describes its equipment as:
```
EGYPTIAN + ETHIOPIAN
```

He assigns it to Sesostris, while reporting that other viewers identified it as **Memnon**.

Modern decipherment identifies the relief and its Hieroglyphic Luwian inscription with **Tarkasnawa, king of Mira**.

Thus one object accumulates:


## TIER C — provenance control generated by Houston's bibliography

### 12. Francis Wilford is a near-perfect evidence-laundering control

Houston relies heavily on Francis Wilford for Puranic `Cusha-Dwipa`, Egypt/Ethiopia, and cross-civilizational identifications.

Wilford's Sanskrit intermediary, Pandit Vidyananda, was later discovered to have altered manuscripts and fabricated large quantities of pseudo-Puranic material; scholarship reports an episode involving roughly 12,000 newly composed verses. Wilford publicly acknowledged that he had been deceived.

This is extremely useful to the project because it demonstrates exactly how a seductive cross-cultural match can acquire false antiquity through an intermediary.

Canonical control:
```
MODERN ANTIQUARIAN CITATION
!=
INDEPENDENT ANCIENT WITNESS
```

and:
```
DERIVED TEXT
-> INTERMEDIARY CONTAMINATION
-> LATER CITATION
!= MULTIPLE WITNESSES
```

Operator:
```
PROV-03 = FORGED_INTERMEDIARY_SOURCE_CONTAMINATION
```

All Houston claims relying materially on Wilford should be routed back to surviving independent Sanskrit witnesses before entering the comparison graph.
