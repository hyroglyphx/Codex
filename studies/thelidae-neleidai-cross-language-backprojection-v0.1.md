# Thelidae / Neleidai Cross-Language Backprojection v0.1

**Date:** 2026-09-24  
**Status:** FIRST TRIANGULATION COMPLETE  
**Question:** Does Diogenes' transmitted `Θηλίδαι` (Thelidai) or Bywater's `Νηλιδῶν / Νηλεῖδαι` (Neleidai) better fit the wider ancient witness network around Thales?

## 1. Greek textual witness

Diogenes Laertius 1.22 transmits:

```text
Θαλῆς ... ἐκ τῶν Θηλιδῶν
Thales ... from the Thelidai
```

and identifies the group as Phoenicians descended from Cadmus and Agenor.

The same sentence continues that Thales came to Miletus with `Νείλεως` / Neileos-Nileos in the transmitted text.

Bywater proposed:

```text
Θηλιδῶν -> Νηλιδῶν
```

The emendation must therefore be tested externally rather than accepted or rejected from Greek sound alone.

## 2. Local Milesian control strongly favors a Neleid clan

Miletian epigraphy independently attests:

```text
πατριᾶς Νειλεϊδῶν
"of the patria/clan of the Neileidai"
```

The Neileidai are therefore not an editor's invented family.

The Miletian founder `Νείλεως / Νηλεύς` is independently embedded in the city's foundation tradition, and later inscriptions explicitly honor Neileus as founder.

Ancient literary tradition also knows the Neleid royal/founding line of Miletus.

This gives:

```text
LOCAL MILESIAN EPIGRAPHY
+ FOUNDATION TRADITION
+ NEILEUS/NILEOS IN DIOGENES' SAME SENTENCE
-> strong historical support for NEIL-/NEL- clan architecture
```

## 3. Callimachus supplies a Thales-specific Neleid association

In the tripod/bowl tradition preserved by Diogenes, Callimachus' dedication addresses Apollo in relation to the people/line of Neleus while naming Thales as the dedicator.

Thus Thales is independently placed in a Neleid/Neleus civic-genealogical environment within an older Hellenistic source quoted by Diogenes.

This materially strengthens the Bywater direction.

## 4. Phoenician semantic backprojection does not favor THEL- = "will"

If the transmitted Thelidai were to be read as a Phoenician family-name meaning something like Greek `thel-` / `thelema` "will, desire," the Phoenician onomastic field should ideally provide a matching carrier.

The currently source-locked Phoenician/Canaanite desire/request field instead includes forms such as:

```text
Phoenician-Punic ʾrš
"desired / requested"

Phoenician proper-name element ḥpṣ-
"delight / desire" field
```

These do not independently reproduce a `THL` carrier.

Therefore:

```text
THELIDAI ~ THELEMA
= strong Greek phonemic attraction
!= presently supported Phoenician lexical backprojection
```

This is important because Diogenes' own ancestry claim identifies the Thelidai as Phoenician.

## 5. Carian/Milesian onomastic ecology

Thales' father's name `Examyas` belongs to a Carian/Anatolian onomastic environment; comparable names include Cheramyes and Panamyes.

This does not identify Thales' clan, but it confirms that the Miletian family environment can mix Greek and Anatolian name carriers.

Therefore a Greek-looking phonemic interpretation of `Θηλίδαι` should not automatically be taken as the historical source-form.

## 6. Current weighted outcome

### Historical clan identity

```text
NEILEIDAI / NELEIDAI
> THELIDAI
```

because Neileidai have:
- local Miletian epigraphic attestation;
- Miletian founder/genealogical tradition;
- Thales-specific Callimachean Neleid association;
- Neileos/Nileos immediately present in Diogenes' narrative environment.

### Greek phonemic reception

```text
THELIDAI
<-> THEL- / THELEMA
```

remains a valid Greek phonemic-reception pathway because the transmitted text actually contains `Θηλίδαι`.

So the two layers are not collapsed:

```text
HISTORICAL BACKPROJECTION -> bends NELEID
TEXTUAL/PHONEMIC RECEPTION -> preserves THELID
```

## 7. Additional Greek semantic lane around NEL-/NĒL-

Greek already has `νηλεής / νηλής`, "pitiless, ruthless," transparently parsed in the lexica as `νη-` + `ἔλεος`.

This is **not** an etymology of Neleus.

But it demonstrates that a Greek hearer also had a semantic field available around `nēl-/nēle-`.

Thus if the historical carrier is Neleid, it too could acquire secondary Greek phonemic attraction independently of its origin.

## 8. Methodological result

This is exactly the cross-language rule in operation:

```text
DO NOT ASK:
Which isolated Greek resemblance feels best?

ASK:
Which candidate survives local epigraphy, neighboring-language forms,
same-referent witnesses, chronology, and receiving-language phonemics?
```

For this case:

```text
historical carrier confidence:
NEILEIDAI = higher

Greek reception value:
THELIDAI/THEL- = retained
```
