# Lemnian / Tyrsenian Research State

Status: **ACTIVE STUDY — D3 Lemnian / D2 Raetic**  
Updated: **2026-09-20**

## Why this source matters

The new Lemnian packet materially deepens the existing Etruscan–Lemnian lane. It provides explicit internal-family evidence rather than merely a label of relationship.

## Witness layer

Primary Lemnian evidence currently represented:

- Kaminia / Lemnos funerary stele,
- Hephaistia inscriptions,
- pottery graffiti,
- Cabeiri sanctuary inscriptions,
- archaic alphabetic adaptation on Lemnos,
- replacement by Attic Greek after Athenian conquest.

The corpus remains small, so absence of a form cannot be treated as strong negative evidence.

## Tyrsenian comparison

Working family:

```text
Common Tyrsenian
├── Raetic
└── Tyrrhenic
    ├── Etruscan
    └── Lemnian
```

The exact internal branching and homeland/migration model remain hypothesis objects, not fixed architecture.

### Morphological correspondences now explicitly tracked

- dative type I: *-si*
- dative type II: *-ale*
- genitive *-s*
- past/perfect *-a-i*
- chronological/numeral morphology such as Lemnian *šialχvis* and Etruscan *šealχls*
- Lemnian *avis* versus Etruscan *avils*

These move Lemnian from a generic Etruscan relation control to an active morphology comparison lane.

## Script-state experiment

Lemnian uses an archaic Greek-derived alphabet, but its exact graphic model is debated.

Track separately:

```text
language genealogy
≠
alphabet genealogy
≠
migration history
```

Current script questions include:
- Samothracian/Aegean model versus direct southern-Etruscan derivation,
- omicron versus upsilon for the back vowel,
- sibilant sign adaptation,
- lambda/mu graphic forms,
- whether apparent punctuation is systemic or scribal/idiosyncratic.

## Archaeology versus language

The file is particularly useful because it explicitly preserves tension between linguistic relationship and archaeological non-equivalence.

```text
Tyrsenian linguistic relation
does not require
Etruscan material-culture identity on Lemnos
```

Possible models to compare:
1. eastward movement from Italy,
2. older Aegean/northern-Aegean distribution,
3. small mobile merchant/mercenary community,
4. language retention amid local cultural assimilation.

No migration model is promoted solely from linguistic similarity.
