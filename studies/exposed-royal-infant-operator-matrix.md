# Exposed Royal Infant Operator Matrix — Sargon / Moses / Gilgamos

Status: ACTIVE / EPISODE-LEVEL COMPARISON
Updated: 2026-09-22

## Purpose

Revisit the older Sargon–Moses comparison after adding Aelian's Gilgamos and the
ONOMASTIC_EPISODIC_REBINDING operator.

The comparison unit is not the whole hero.

It is the episode bundle:

```text
succession / social threat
→ constrained or secret maternity
→ extraordinary or hidden birth
→ exposure at boundary
→ rescue
→ foster/adoptive upbringing
→ later elevated destiny
```

Each component is scored independently.

Attested Akkadian birth legend:

```text
high-priestess mother
→ secret conception/birth
→ reed basket
→ bitumen sealing
→ river exposure
→ Aqqi the irrigator rescues
→ adopted/raised
→ date-grove work
→ Ishtar's favor
→ kingship
```

Source:
- ETANA, *The Birth-Legend of Sargon*:
  https://etana.org/node/578

Important chronology:
The surviving composition is much later than Sargon's historical reign.
Therefore:

```text
narrated birth era
!=
composition/witness era
```

This is a Four-Clocks control.

## Witness B — Moses, Exodus 2

Episode bundle:

```text
royal decree threatens male Hebrew infants
→ mother conceals child
→ papyrus/reed container
→ bitumen/pitch sealing
→ Nile placement
→ Pharaoh's daughter discovers/rescues
→ mother re-enters as nurse
→ palace adoption
→ later liberator role
```

The overlap with the Sargon birth legend is structurally concentrated in:

```text
hidden birth
+ reed container
+ waterproofing
+ river exposure
+ rescue/adoption
+ later elevated role
```

But the social logic differs:
- Sargon: maternal status/illegitimacy or secrecy frame;
- Moses: state violence against a population.

Therefore shared operator sequence does not mean same ideological function.

## New distinction — Foster-role covariance

Sargon and Gilgamos both move toward an agricultural foster environment:

```text

↔

```

This is more specific than generic adoption.

It should be scored as:

```text
FOSTER_ROLE
= irrigator / gardener / cultivator
```

rather than merely:
```text
rescuer
```

This is a candidate relational residue worth tracking across later retellings.

## What the newer Gilgamesh findings change

Before Aelian, the Sargon–Moses comparison could be treated as a two-text exposure parallel.

After Aelian:

```text
exposed-child motifs are demonstrably mobile enough
to attach to a different famous Mesopotamian king
```

at least by the Roman-period witness.

That does not prove a common source for all three.

It does strengthen the historical plausibility of:

```text
motif circulation
+ episode recombination
+ identity rebinding
```

as real transmission mechanisms.
