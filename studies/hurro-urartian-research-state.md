# Hurro-Urartian Research State

Status: **RECOVERED + VERIFIED + GAP-MAPPED**  
Updated: **2026-09-20**

## Current conclusion

The project has explored a substantial part of the Hurro-Urartian lane, but not all of the deeper-origin proposals.

The secure baseline is:

```text
Hurrian ↔ Urartian = genetic Hurro-Urartian relationship
external family links = unproven candidates
typological resemblance ≠ ancestry
archaeological correlation ≠ linguistic genealogy
```

## Secure family layer

Hurrian is the only securely established cognate of Urartian. The project therefore treats **Hurro-Urartian** as a small genetic family whose external affiliations are unresolved.

Urartian is especially close to the conventionally named **Old Hurrian** dialect. A scholarly estimate places the split not much later than roughly 2000 BCE, but the project has not yet built its own Proto-Hurro-Urartian sound/morphology reconstruction.

### Required next object

```text
PHU = (
  reconstructed phoneme inventory,
  case morphology,
  agreement/indexing,
  derivational suffixes,
  verbal morphology,
  lexicon,
  correspondence sets,
  chronology,
  witness support
)
```

Do not fill PHU from typology alone.

## Morphology / alignment layer

Hurrian and Urartian are both strongly useful for the project's operator-memory work because of:

- ergative-absolutive alignment,
- agglutinative/suffixing morphology,
- long morpheme chains,
- rich nominal case behavior,
- pronominal/clitic indexing,
- derivational and verbal suffix sequencing.

Prior work already planned probes for role reassignment, suffix order, valency/causatives, reciprocal/reflexive behavior, nominalization, motion and subordination.

## Scribal transition layer

Recovered prior work already treated early Urartian royal writing as an excellent carrier/readout example:

```text
Neo-Assyrian language + cuneiform
→ Urartian language + adapted Neo-Assyrian cuneiform
```

This is not merely a language change. It is a controlled case in which:

- script carrier persists,
- language readout changes,
- royal formulae/titles show institutional continuity,
- bilinguals provide a return path.

Priority witnesses include Sarduri I, Išpuini, Menua, Kal-e Šīn, Topzawa, and later royal inscriptions.

## Armenian contact / substrate layer

Prior Armenian work already treated the Armenian Highlands as a reticulated contact system rather than a simple replacement chain.

The useful model is:

```text
Hurro-Urartian substrate/contact
        +
Proto-/Early Armenian development
        +
Iranian / Anatolian / Aramaic / Greek / Caucasian contact
        ↓
historical Armenian
```

The project previously assembled a cautious small set of high-confidence Hurro-Urartian loan candidates, including the well-known Armenian **xnjor 'apple'** comparison with Hurrian **hinzuri**.

Do not encode:

```text
Urartian fell → Armenian simply replaced it
```

as a single event. Use typed transitions: demographic shift, political succession, language shift, substrate retention, borrowing, and administrative continuity are separate variables.

## External-relation hypotheses

### Northeast Caucasian / Nakh-Daghestanian

**Status: live but unproven.**

This hypothesis has been discussed in prior work and is now formally registered as an external candidate lane.

Required proof burden:

1. regular sound correspondences,
2. shared basic vocabulary beyond chance,
3. shared morphological paradigms,
4. chronological plausibility,
5. genealogical controls,
6. areal-contact alternative,
7. blind holdout tests.

### Kura-Araxes

**Status: genuine gap.**

We have not yet built a Kura-Araxes ↔ Hurro-Urartian study. It should be treated as an archaeological correlation problem:

```text
archaeological horizon
≠
language family
```

Test settlement chronology, geography, continuity/discontinuity, and later Hurrian distribution before assigning linguistic identity.

### Sumerian

The project has compared Hurrian and Sumerian typologically—especially agglutination and ergative behavior—and used Sumerian as a carrier failure/control in the numeral work.

It has **not** tested a Sumerian–Hurro-Urartian protolanguage hypothesis. Any such study must begin from correspondence sets and morphology, not shared typology.

### Kartvelian

Kartvelian currently functions as a Caucasian external control for consonant-rich phonotactics and numeral-carrier testing. It is not currently treated as genetically related to Hurro-Urartian.

### Tyrsenian / Etruscan

Etruscan currently belongs to the western Mediterranean/Pyrgi/numeral lanes. The secure Etruscan–Lemnian Tyrsenian relationship is kept separate from any proposed Hurro-Urartian connection.

A 2026 paper arguing an Etruscan–Hurro-Urartian genealogical relation is suitable for adversarial review, but it has not yet been incorporated or validated by this project.

## Next development sequence

1. **PHU morphology table:** Hurrian ↔ Urartian cases, suffix order, clitics, verbal markers.
2. **Old Hurrian bridge:** isolate features where Urartian patterns specifically with Old Hurrian.
3. **Urartian witness pack:** Sarduri I → Išpuini → Menua; bilingual and formula comparison.
4. **Armenian contact pack:** exact loan candidates with semantic domain, phonology, chronology, and competing etymologies.
5. **Northeast Caucasian adversarial test:** reproduce strongest published correspondence sets and attack them with chance/contact controls.
6. **Kura-Araxes corridor:** archaeology-only first; language attribution withheld.
7. **Sumerian/Kartvelian/Etruscan candidate review:** each tested independently; no composite macro-family shortcut.
