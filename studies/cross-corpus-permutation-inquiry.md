# Cross-Corpus Permutation Inquiry

Status: ACTIVE METHOD
Updated: 2026-09-21

## Purpose

Lessons discovered in one corpus become probes applied to another corpus.

The operation is not:
```text
A resembles B
```

It is:
```text
lesson L discovered in A
→ formulate test T_L
→ apply T_L to B
→ compare against anchor corpus C
→ update both A and B
```

This creates a recursive research chain.

## Portable lessons

### L1 — WORK != FIXED TEXT
Learned strongly from Gilgamesh, Homer, biblical textual plurality.

Test:
Does the target corpus represent one textual state, a recension, a translation, an oral multiform, a rewritten text, or a historiographic recomposition?

### L2 — NAME != IDENTITY != ROLE
Learned from:
- Ziusudra / Utnapishtim / Atrahasis / Noah / Xisouthros
- Bardiya / Smerdis / Tanaoxares
- Gaubaruva / Gubaru / Gobryas

Test:
Separate phonetic/name equivalence, entity identity, narrative role, and operator role.

### L3 — NATIVE-FORM ACCOMMODATION
Learned from Hurrian→Hittite, Greek→Latin, Hebrew→Greek/Aramaic/Latin.

Test:
Which architecture survives after the receiving language replaces source syntax, formula, meter, and idiom with native conventions?

### L4 — RECENSION CAN PRESERVE AND REWRITE
Learned from:
- Sumerian Gilgamesh poems → Akkadian epic
- Old Babylonian → Standard Babylonian
- Genesis/Exodus → Jubilees
- Pentateuchal past → Deuteronomic recapitulation
- Homeric multiforms → Alexandrian/medieval states

Test:
What was preserved, relocated, expanded, omitted, or ideologically refunctionalized?

### L5 — PERIPHERAL WITNESSES MATTER
Learned from:
- Hattusa/Ugarit/Emar/Megiddo Gilgamesh
- Qumran Hebrew/Aramaic versus later complete translations
- Homeric papyri versus medieval manuscripts

Test:
Can a geographically or chronologically peripheral witness preserve an earlier or alternate state absent from the canonical center?

### L6 — WITNESS CLOCK != NARRATIVE CLOCK
Learned from Xenophon and later manuscript transmission.

Test:
Which features belong to the narrated era, which to the author/editor, and which to the surviving manuscript?

### L7 — TRANSLATION DIFFERENCE != TRANSLATOR FREEDOM AUTOMATICALLY
Learned from biblical textual plurality.

Test:
Could the target witness reflect a different source Vorlage rather than a free translation?

### L8 — PACE IS LANGUAGE-SPECIFIC
Learned from Homeric hexameter, Babylonian parallelism, Hebrew poetic/recurrence structure.

Test:
Do not ask whether target language preserves source meter. Ask whether it rebuilds the structured text through its own prosodic/formulaic conventions.

### L9 — MULTILINGUAL NEXUS OUTRANKS REMOTE RESEMBLANCE
Learned from Hattusa, Ugarit, Letoon, Behistun, Rosetta.

Test:
Is there an actual contact/scribal environment that demonstrates the required transform class?

### L10 — NEGATIVE CONTROL IS PART OF THE CLAIM
Learned from numeral studies and false/withdrawn Gilgamesh identifications.

Test:
What evidence would make this proposed relationship fail?

### L11 — DECIPHERMENT HEURISTIC != FINAL ETYMOLOGY
Learned from Hittite decipherment.

A resemblance can be useful for generating a reading hypothesis without remaining the best final etymology.

Test:
Did the proposed clue merely open the solution-space, or does it survive modern phonology, morphology, chronology, and comparative reconstruction?

### L12 — NAME CONTINUITY != PLOT OR CLASSIFIER CONTINUITY
Learned from Aelian's Gilgamos and the Qumran Book of Giants.

Test:
Separate name carrier, entity, role, classifier, episode set, companion network, and receiving tradition.

### L13 — SAME SCRIPT != SAME LANGUAGE
Learned from Hittite cuneiform and multilingual cuneiform archives.

Test:
Before comparing sign strings, identify whether the carrier is phonetic, logographic, heterographic, or borrowed from another writing-language tradition.

### L14 — CALIBRATE ON ANCIENT CROSSWALKS BEFORE REMOTE CANDIDATES
Learned from Rosetta, Behistun, Tell Fekheriye, KTU 5.14, and Ebla.

Test:
What documented transformation class is closest to the candidate relation, and what deformation does that anchor actually permit?

### L15 — DEPENDENCE CORRECTION PRECEDES CONVERGENCE COUNTING
Learned from translation genealogy and numeral-seven null modeling.

Test:
How many independent generating paths exist after genealogy, borrowing, recension, and shared intermediaries are collapsed?

### L16 — MORPHOLOGY PRECEDES FEATURE EXTRACTION
Learned from the numeral-seven root/stem normalization pass.

Test:
Is the apparent feature inside the lexical stem, or introduced by gender, number, case, inflection, complement, or orthographic convention?

### L17 — PREDICTION OUTRANKS RECOGNITION
Learned from Hittite decipherment covariance.

Test:
Does the proposed model predict additional forms, endings, syntactic behavior, or aligned witnesses outside the original clue?

## Permutation 01 — Gilgamesh lessons → Xenophon / Cyropaedia

### G→X1: Treat Cyropaedia as a textual state, not "Persian history"
Gilgamesh teaches that a famous work can be a late integrated state built from older materials.

Inquiry:
```text
Iranian / Median / Babylonian historical material
+ Greek oral/written reports
+ Xenophon's 4th-c. political/ethical program
→ Cyropaedia narrative state
```

Do not demand that every element share one historical date.

### G→X2: Separate name, identity, and role
Apply the flood-name lesson directly.

```text
Ziusudra != Utnapishtim as phonetic form
but may occupy inherited flood-survivor address
```

therefore:

```text
Bardiya / Smerdis / Tanaoxares
Cyaxares-name / Cyaxares-person
Gaubaruva / Gubaru / Gobryas
```

must receive separate:
- NAME_EQUIVALENCE
- ENTITY_IDENTITY
- ROLE_EQUIVALENCE
scores.

### G→X3: Peripheral witnesses can outrank literary center
Gilgamesh at Hattusa/Megiddo/Ugarit teaches us to seek non-Greek controls for Xenophon.

For every Xenophontic Iranian entity, prioritize:
Old Persian + Babylonian + Elamite + Aramaic + Hebrew/Armenian controls before evaluating Greek narrative coherence.

### G→X4: Recension/recomposition is not error
The Akkadian epic preserves older material while reorganizing it.

Apply to Xenophon:
A historical core may survive inside a pedagogical/idealized narrative even if sequence, kinship, chronology, or speeches are recomposed.

The test is not "true or false Cyropaedia."
It is:
```text
which layer is documentary?
which layer is traditional?
which layer is Greek accommodation?
which layer is Xenophontic construction?
```

### G→X5: Native form accommodation
Hittite Gilgamesh does not need Akkadian cadence.

Likewise Greek Cyropaedia does not need Persian court discourse to retain Persian syntax or oral form.

Test Iranian institutional concepts for:
- Greek functional translation,
- Greek political vocabulary substitution,
- preserved hierarchy,
- preserved decimal organization,
- changed rhetoric.

### G→X6: "even to this day" as recension marker
Standard Babylonian Gilgamesh contains older matter inside a later textual state.

Xenophon's "even now/even to this day" statements can be treated as explicit seams where 4th-c. observation enters a 6th-c. narrative.

Use these as chronological boundary markers.

### G→X7: Pace transformation
Ask whether repeated royal speech frames, counsel scenes, military enumeration, procession, benefaction/reward, and obedience formulas form a Greek prose pacing system that regularizes foreign political material.

Do not search for Persian meter in Xenophon.

### G→X8: Narrative-role substitution
In Gilgamesh flood transmission, actor names can change while operator positions remain stable.

Test Xenophon episodes for:
```text
historical actor changed?
role preserved?
office preserved?
sequence preserved?
moral function reassigned?
```

Gobryas is a priority case.

## Permutation 02 — Xenophon lessons → Gilgamesh

### X→G1: Exonym/onomastic lens
Use Xenophon's Iranian name orbits to revisit:
- Bilgames/Gilgamesh
- Huwawa/Humbaba
- Ziusudra/Utnapishtim
- Xisouthros

Do not equate phonological distance with narrative distance.

### X→G2: historiographic retrojection
Ask whether later Babylonian scribal/editorial institutions or theological assumptions have been projected into legendary Uruk.

This is an inquiry, not a current conclusion.

### X→G3: office/title translation
Track royal titles and institutional vocabulary across Sumerian and Akkadian states with the same care used for satrapēs and chiliarchos.

### X→G4: Greek recoding
Use Xenophon's Greek naturalization as a control for Berossus:
What happens when Babylonian tradition is retold for Greek readers?

## Permutation 03 — Gilgamesh lessons → Homer

- treat Homer as transmission ecology, not fixed ur-text;
- separate oral multiform from corruption;
- compare peripheral papyri to canonical medieval state;
- use Hattusa as historical proof that eastern heroic narratives can be translated/adapted westward;
- compare narrative architecture independently from hexameter;
- use Tablet XII as a control for older material inserted into a later epic whole.

## Permutation 04 — Homer lessons → Gilgamesh

- test formulaic slot behavior rather than only motifs;
- map repeated epithets/formulae by narrative domain;
- distinguish performance-compatible variation from scribal recension;
- test whether Akkadian repeated clauses occupy stable discourse positions analogous to formulaic slots even without quantitative meter.

## Permutation 05 — Torah/Jubilees lessons → Gilgamesh/Xenophon

Rewritten scripture teaches:
```text
retelling can be conservative at architecture level
while radical at chronology/explanation level
```

Apply to:
- Standard Babylonian editorial integration,
- Berossus,
- Xenophon's Cyrus narrative.

Deuteronomic recapitulation teaches that repetition can create a new covenantal/political state rather than merely duplicate text.

Apply to repeated royal speeches, succession scenes, and institutional restatements.

## Permutation 06 — Gilgamesh/Hattusa lessons → Torah

Hattusa demonstrates that source material can be:
- translated,
- paraphrased,
- omitted,
- expanded,
- syntactically naturalized,
while remaining recognizably the same literary object.

Use this deformation envelope when comparing:
- Hebrew ↔ Septuagint,
- Hebrew ↔ Targum,
- Hebrew ↔ Syriac,
- Hebrew/Greek ↔ Latin.

But first test for different source Vorlage.

## Permutation 07 — Amenemope / treaty lessons → Xenophon

Amenemope→Proverbs:
a foreign wisdom complex may survive after reordering and local theological reframing.

Esarhaddon treaty→Deuteronomy:
an imperial political operator may survive after ideological reassignment.

Apply to Cyropaedia:
Persian court/military institutions may be preserved while their ethical explanation is thoroughly Xenophontic/Greek.

## Permutation 08 — Ahiqar / Enoch / Jubilees lessons → fragmentary corpora

A later complete translation can preserve older material lost in the source language.

Apply cautiously to:
- Hittite/Hurrian Gilgamesh,
- lost Epic Cycle material,
- Berossus fragments,
- later Armenian/Syriac/Arabic witnesses of older traditions.

Never assume later completeness equals earlier originality.

## Permutation 09 — pace lessons across all corpora

For each aligned episode calculate:

```text
A = architecture
D = discourse/formula
P = pace/prosody
N = names/onomastics
I = institutional vocabulary
R = ideological recoding
```

The target transform is:

```text
T = Δ(A,D,P,N,I,R)
```

A strong transmission candidate can have:
- low ΔA,
- high ΔP,
- moderate ΔD,
- high ΔN,
and still be historically plausible if the anchor corpus shows the same transform class.

## Cross-corpus benchmark — PERM-01

Start with six episodes/objects:

1. Gilgamesh flood / Utnapishtim
2. Huwawa/Humbaba
3. Cyrus/Gobryas in Cyropaedia
4. Homeric heroic death/fame
5. Genesis/Jubilees recapitulation
6. Deuteronomic treaty/covenant curse structure

For every ordered pair A→B:
- state the lesson exported from A,
- formulate a test on B,
- nominate the nearest anchor,
- identify expected native-form accommodation,
- identify a negative control,
- assign what new evidence would promote/demote the edge.

This creates 30 directed cross-corpus probes from six objects.

## Promotion rule

A permutation does not promote a historical claim by itself.

It promotes an **inquiry** when:
1. the transform is observed elsewhere,
2. chronology permits it,
3. geography/contact permits it,
4. target-language accommodation is plausible,
5. negative controls do not erase the signal.

Only then return to the historical edge for promotion.
