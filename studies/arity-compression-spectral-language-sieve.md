# Arity–Compression Spectral Language Sieve

Status: ACTIVE / TESTABLE HYPOTHESIS
Updated: 2026-09-21

## Purpose

Add an explicit arity/compression dimension to the Nexus / ECVR / TCIM / Intermediate Language Ring stack.

The target question is not simply whether one-, two-, or three-consonant structures are older. It is whether different writing and language systems expose the same underlying information at different resolutions.

The governing separation is:

```text
SIGN ARITY != PHONETIC LOAD != ROOT ARITY != MORPHOLOGICAL COMPLEXITY != SEMANTIC COMPRESSION
```

A one-sign logogram can carry a whole lexical/semantic address.
A one-sign Egyptian phonogram can carry one, two, or three consonants.
An abjad can distribute a consonantal root across separate signs.
A spoken lexical root can enlarge independently of how any script chooses to represent it.

Therefore no single linear chronology is assumed.

## Spectral model

Treat each witness as:

```text
A(X) = (
  graphic_arity,
  phonological_load,
  root_arity,
  morphological_complexity,
  semantic_compression,
  classifier_context_load,
  chronology,
  geography,
  witness
)
```

The spectral hypothesis is:

```text
compressed carrier
    -> progressively explicit decomposition
    -> higher visible resolution
```

This is a representational relation first.

A separate chronological hypothesis asks whether, in particular families and lexemes, lower root arity can also precede later enlargement:

```text
C1C2 -> C1C2X
C1C2 -> C1C2C2
XC1C2 -> C1C2C3
```

That claim must be tested lexeme-by-lexeme and family-by-family.

## Egyptian control

Egyptian is a high-value calibration system because a single script can deploy:

- logograms,
- uniliteral phonograms,
- biliteral phonograms,
- triliteral phonograms,
- phonetic complements,
- determinatives/classifiers,
- non-linear graphic grouping.

This lets the project compare multiple encoding resolutions without pretending that one sign equals one phoneme or one morpheme.

Core control:

```text
graphic arity = 1
phonetic load = 1 | 2 | 3 consonants | lexical/logographic value
```

This directly tests the ILR rule:

```text
carrier != reading != language != semantic address
```

## Cuneiform / logographic control

Sumerian and Akkadian provide a second calibration lane:

```text
one visible carrier
-> logographic value in one environment
-> syllabic or lexical readout in another
-> language-specific morphology outside the carrier
```

This is representational decompression / alternate readout, not automatically root genealogy.

## Semitic root-arity lane

For Semitic material, index separately:

1. written consonantal skeleton,
2. reconstructed lexical root,
3. inflectional/derivational additions,
4. gemination/reduplication,
5. candidate root enlargement,
6. later orthographic stabilization.

Do not assume all triliteral roots descend from biradicals.

Instead test whether specific families admit a smaller kernel that predicts the larger forms.

Current benchmark:

```text
Ḫ-S-S
-> test candidate Ḫ-S + extension/gemination
```

Akkadian ḫāsis / ḫasīsu and Ugaritic ḫss belong to the primary H-S-S wisdom/intelligence comparison lane.
The proposed deeper Ḫ-S kernel remains CANDIDATE until historical morphology and correspondence evidence licenses the reduction.

ASIS-like surface forms in unrelated languages remain controls unless their own morphology establishes a path.

## Indo-Iranian / Indo-European control

Root enlargement and consonantal extension provide an independent control family.

The question is not whether Indo-European and Semitic share the same root system.
The question is whether both preserve demonstrable mechanisms of:

```text
compact lexical root
-> consonantal extension
-> differentiated lexical state
```

This helps distinguish a general language strategy from a specifically Semitic genealogy.

## New sieve stack

For every candidate, run:

```text
WITNESS
-> SIGN_ROLE
-> GRAPHIC_ARITY
-> PHONETIC_LOAD
-> ROOT_ARITY
-> MORPHOLOGICAL_EXPANSION
-> SEMANTIC_ADDRESS
-> CHRONOLOGY
-> CONTACT_PATH
-> NEGATIVE_CONTROL
```

Then apply existing operators:

- STRIP — remove declared layers only.
- TRANSVERSE — compare different representation dimensions.
- POSITION SWEEP — test carrier survival in initial/medial/final/cross-boundary positions.
- DIALECT ORBIT — preserve attested pronunciation variation.
- PARALLEL_READOUT — allow one carrier to support multiple language-specific readings.
- PHASESHIFT — preserve process identity while lexical items occupy different phases.
- SURGERY — remove pathological edges without discarding the larger manifold.
- VOLS — type every relation and prevent resemblance from silently becoming descent.

## Arity–Compression Index

Define a comparison vector:

```text
ACI(X) = (G, P, R, M, S, C)
```

where:

- G = graphic arity,
- P = phonological load,
- R = root/radical arity,
- M = morphological expansion,
- S = semantic compression,
- C = classifier/context dependence.

The index is descriptive, not a universal evolutionary ladder.

## Chronology discipline

Two claims must always remain separate:

### Spectral precedence
A lower-dimensional or more compressed representation can occupy an earlier position in a decomposition spectrum.

### Historical precedence
A form or mechanism is actually earlier in time according to witnesses, reconstruction, sound law, morphology, and contact history.

The first does not prove the second.

Operational rule:

```text
spectral order != chronological order
unless independently demonstrated
```

## Primary test corpora

1. Egyptian hieroglyphic uniliteral/biliteral/triliteral/logographic contrasts.
2. Sumerian logogram -> Akkadian readout environments.
3. Ebla bilingual lexical material.
4. Ugaritic consonantal writing and multilingual lexical archives.
5. Hebrew / Aramaic / Arabic Semitic root families.
6. Hittite/Hurrian/Akkadian heterogeneous scribal environments.
7. Vedic Sanskrit / Avestan / Indo-Iranian root-extension controls.
8. Rosetta, Behistun, Tell Fekheriye, Karatepe/Cinekoy, Letoon and other multilingual calibration nodes.

## Promotion standard

A proposed root reduction or enlargement is promoted only when at least one strong path exists through:

- attested alternation,
- productive morphology,
- regular sound correspondence,
- historical derivation,
- bilingual/lexical witness,
- recurrent family behavior,
- or another independently constrained mechanism.

Surface shortening by itself remains a declared analytical projection.

## Project consequence

The Nexus should no longer index "word length" as one scalar.

It should index at minimum:

```text
sign count
phoneme count
radical count
morpheme count
semantic payload
classifier/context payload
```

This gives higher resolution for comparing hieroglyphic, cuneiform, logographic, syllabic, consonantal and alphabetic representations while preserving their differences.
