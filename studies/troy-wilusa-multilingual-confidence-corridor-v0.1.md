## 1. Why this transcript is useful

The strongest value is not the speculative language-identification menu. It is the dense cluster of Bronze Age cross-language names around western Anatolia:

```text
Wilusa ~ (W)ilios
Taruisa ~ Troia
Alaksandu ~ Alexandros
Appaliuna ~ Apollo/Apellon
Ahhiyawa ~ Achaean/Achaiwia
Millawanda ~ Miletos
Apasa ~ Ephesos
Lazpa ~ Lesbos
```

These do not all have equal confidence. Together they can form a Hittite<->Greek foreign-name calibration corridor.

## 2. Wilusa <-> (W)ilios

Wilusa is now commonly located in the Troad and often identified with Ilios/Troy. The Greek city-name Ilios is conventionally reconstructed with an older initial digamma: *Wilios.

Thus:

```text
Hittite Wilusa
<->
Greek *Wilios > Ilios
```

is a high-value same-referent carrier candidate.

Status: HIGH / prevailing identification, not absolute proof.

Add:

```text
TRN-10 = HITTITE_GREEK_TOPONYM_BACKPROJECTION
```

## 3. Taruisa <-> Troia must be kept distinct from Wilusa <-> Ilios

Hittite sources list Wilusiya and Taruisa side-by-side. Greek later has both Ilios (city) and Troia/Troas (city/region usage varying by period).

The temptation is:

```text
Wilusa = Ilios
Taruisa = Troia
```

but Hittite classifier usage does not reproduce the later Greek city/region distinction neatly. Both can appear as lands/countries.

Therefore:

```text
DUAL TOPONYM SURVIVAL = plausible
EXACT ADMINISTRATIVE EQUIVALENCE = unresolved
```

Add:

```text
NAME-CAND-17 = WILUSA_TARUISA_ILIOS_TROIA_DUAL_CARRIER
```

## 4. Alaksandu is the strongest personal-name bridge

Muwatalli II's treaty is with Alaksandu, ruler of Wilusa.

Alaksandu has long been compared with Greek Alexandros. Modern work generally treats this comparison as strong; the structure of Alexandros is transparent Greek ('protector/defender of men'), and the name-family is independently Bronze Age Greek because Linear B attests feminine `a-re-ka-sa-da-ra` = Alexandra.

This yields:

```text
MYCENAEAN a-re-ka-sa-da-ra
          | Greek name-family
          v
Alexandros
          | Hittite foreign-name accommodation
          v
Alaksandu of Wilusa
```

Important ceiling:

```text
GREEK PERSONAL NAME AT WILUSA
!=
GREEK-SPEAKING POPULATION OF WILUSA
```

Possible mechanisms include elite bilingualism, dynastic marriage, prestige naming, personal migration, or Greek-speaking ruling-family contact.

Add:

```text
NAME-13 = ELITE_NAME_WITHOUT_POPULATION_LANGUAGE
```

## 5. Appaliuna <-> Apollo is more interesting for directionality than identity

The Alaksandu treaty includes a deity written Appaliuna/Appaliunas. Comparison with Greek Apollo/Apellon is serious but less secure than Alaksandu/Alexandros because the cuneiform divine name is imperfectly preserved and the direction of borrowing is disputed.

One major proposal reverses the usual intuition:

```text
ANATOLIAN APPALIUNA
->
GREEK APOLLON
```

rather than Greek Apollo being imported into Wilusa.

This is exactly the project's reception problem:

```text
SAME / NEAR-SAME DIVINE CARRIER
does not determine
DIRECTION OF TRANSMISSION
```

Add:

```text
DIV-CAND-07 = APPALIUNA_APOLLON_DIRECTIONALITY_TEST
```

## 6. Luwian seal: script does not identify Trojan language

The hieroglyphic seal from Hisarlik is genuine and important, but it cannot establish that 'the Trojans spoke Luwian.'

Specialist treatment notes that the seal uses Hieroglyphic Luwian script, but the names are uninflected and the titles logographic; therefore the language encoded by the seal cannot actually be determined.

This supplies a perfect project control:

```text
SCRIPT = LUWIAN
!=
LANGUAGE = LUWIAN
!=
POPULATION IDENTITY = LUWIAN
```

Add:

```text
SCR-02 = SCRIPT_LANGUAGE_NONIDENTITY
```

## 8. Archaeology cannot by itself choose the language

Mycenaean pottery and architectural parallels at Troy demonstrate contact and selective cultural convergence, not population language.

Likewise Hittite political control does not make Wilusa Hittite-speaking.

Therefore keep four coordinates separate:

```text
MATERIAL CULTURE
POLITICAL OVERLORDSHIP
PERSONAL-NAME ORIGIN
LOCAL SPOKEN LANGUAGE
```

## 9. Best current language model

The evidence currently supports a multilingual/contact-zone model better than any single-language declaration:

```text
LOCAL TROJAN/WILUSAN SPEECH = unknown

+ Hittite diplomatic-administrative interface
+ Anatolian regional contact
+ Greek/Ahhiyawan elite and commercial contact
+ possible Luwian scribal interface
+ later Aeolian Greek acculturation
```

This is compatible with more than one spoken language or register inside the polity.
