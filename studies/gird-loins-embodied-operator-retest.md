## 1. Hebrew physical-semantic anchor

Biblical Hebrew `māṯnayim` denotes the waist/loins region.

Lexicographic evidence explicitly connects "girding the loins" with making ready for action.

Examples include:
- Exodus 12:11,
- 1 Kings 18:46,
- 2 Kings 4:29,
- 2 Kings 9:1,
- Jeremiah 1:17.

Reference:
https://biblehub.com/strongs/hebrew/4975.htm

Thus the embodied sequence is historically grounded:

```text
waist/loins
+ gird/bind
→ readiness for movement/action
```

not merely a later English idiom.

## 3. Isaiah 45 gives the inverse operator — crucially in the Cyrus context

Isaiah 45:1 uses the opposite bodily-political action with Cyrus:

```text
"loins of kings" loosened
```

Lexicographic discussion understands the expression as disabling/disarming royal strength.

This creates a striking inverse pair:

```text
GIRD LOINS
→ READY / STRENGTHEN / MOBILIZE

LOOSEN LOINS
→ DISABLE / DISARM / DE-MOBILIZE
```

and the second appears specifically in the Cyrus-anointed passage.

This matters because it converts the loins image from a loose metaphor into a reversible operator.

Define:

```text
BODY_BINDING_STATE
↔
ACTION_CAPACITY
```

The sign of the transformation can reverse.

## 5. Translation consequence

When a Greek, Latin, English, Syriac, Arabic, Persian or other target text uses a readiness idiom,
do not ask first whether it literally says "loins."

Ask:

```text
BODY REGION
ACTION ON BODY/CLOTHING
MOBILITY CONSEQUENCE
READINESS/POWER CONSEQUENCE
REGISTER
```

Then compare.

Possible cases:

### lexical preservation
source and target both explicitly use waist/loins + binding.

### operator preservation
source uses a native readiness construction while target translates with a loins idiom.

### target-culture overlay
English translator inserts "gird up your loins" where the source only means "be ready," "lightly equipped," or "prepared."

These must receive different relation types.

