```text
  SAME_REFERENT_CROSS_SCRIPT: A ~0.97
```

Interpretation: this node is already suitable for 4D mapping. The medial coronal {ṯ/š/s} should be treated as a variable coordinate, not normalized away.

## 4. LADY / MISTRESS — a semantic dense node across unrelated languages

```text

```

These form an extremely strong semantic/operator node:

```text
SEMANTIC_TRANSLATION / TITLE FUNCTION: A/B ~0.88-0.98
```

High-priority structural question: whether localized LADY/MISTRESS title systems behave similarly under cult translation.
