## Priority 1 — Nannas bilingual: direct personal-name and divine-name translation

Late Lydian/Persian Sardis preserves:

```text
Lydian: nannaś bakivalis artimuλ
Greek:  Νάννας Διονυσικλέος Ἀρτέμιδι
```

The ancient publication glosses:

```text
Bakivas <-> Dionysikles
Artimu- <-> Artemis
```

and Sardis religious evidence independently identifies Lydian Baki- with Bacchus/Dionysos.

This is therefore a top-grade same-artifact test for:

```text
NATIVE THEOPHORIC NAME
-> SEMANTICALLY/RELIGIOUSLY EQUIVALENT GREEK NAME
```

without requiring phonetic resemblance.

Add:

```text
ONOM-10 = SAME_ARTIFACT_THEOPHORIC_NAME_TRANSLATION
DIV-09 = SAME_ARTIFACT_DIVINE_NAME_EQUIVALENCE
```

## Priority 2 — Manes bilingual: Lydian + Aramaic + Artaxerxes

The stele of Manes son of Kumlis at Sardis is dated by the Aramaic text to year 10 of Artaxerxes; stylistic and philological arguments favor 394 BCE, Artaxerxes II.

Key structure:

```text
LYDIAN legal/funerary text
+ ARAMAIC parallel
+ PERSIAN regnal dating
+ ARTEMIS OF EPHESUS
+ ARTEMIS OF KOLOE
```

The Aramaic version secures the meaning of otherwise difficult Lydian clauses.

This is almost an ideal lattice object because one artifact ties local language, imperial administrative language, imperial chronology, and regional cult geography together.

Add:

```text
TRN-18 = IMPERIAL_ARAMAIC_LOCAL_LAW_PARALLEL
CHRON-02 = REGNAL_DATE_CROSS_SCRIPT_ANCHOR
```

### Mnemon cross-link

The stele's likely king is Artaxerxes II Mnemon. Greek `mnēmōn` belongs to the 'mindful/remembering' field. This should remain a Greek epithet/reception lane, but it makes Sardis a concrete historical intersection for the project's recent Memnon/Mnemon royal-name cluster.

## Priority 3 — Xanthus the Lydian: local ancient linguistic testimony

Xanthus, probably from Sardis and regarded in antiquity as a Lydian authority, preserves two unusually valuable claims:

1. Lydian and Torrhebian differed only slightly, like Ionian and Dorian.
2. An older name of Sardis was `Xuáris`, which modern scholarship notes fits epichoric Lydian `śfar(i)-`.

This supplies:

```text
ANCIENT DIALECT-CONTINUUM TESTIMONY
+ LOCAL TOPONYMIC MEMORY
+ LOCAL AUTHOR CONTROL
```

Add:

```text
LANG-07 = ANCIENT_REPORTED_DIALECT_CONTINUUM
NAME-19 = LOCAL_TOPONYMIC_MEMORY_CONTROL
```

## Priority 6 — script ancestry != language ancestry

Lydian is an Anatolian Indo-European language, while its alphabet is derived from a Greek alphabetic model.

This is a compact control:

```text

!=
GREEK LANGUAGE
```

and belongs directly beside Carian, Luwian-seal, Hittite-heterogram and Urartian controls.

Add:


## Priority 8 — monetary/metrological carrier survives regime change

Lydia's early coinage and Lydo-Milesian weight standard spread into Ionian and other Aegean mints. After the Persian conquest, Croesid practice continued before Darius introduced the daric/siglos system.

Thus:

```text
LYDIAN QUANTITATIVE STANDARD
-> REGIONAL ADOPTION
-> PERSIAN REFORM
```

This is a non-linguistic carrier model in which numerical equivalence, material weight, and political authority can be tracked independently.

Add:

```text
MET-01 = METROLOGICAL_CARRIER_ACROSS_REGIME_CHANGE
```

## Priority 10 — ancient-source contradiction: Lydia and the Tyrrhenians

Herodotus gives a Lydia -> Tyrrhenia migration under Tyrrhenus.

Xanthus of Lydia, as quoted by Dionysius, knows no Tyrrhenus or Lydian colonization of Italy and instead preserves Lydus/Torebus with closely related Lydian/Torrhebian speech.

Hellanicus gives yet another model: Pelasgians -> Tyrrhenians after migration to Italy.

Therefore this is a prime adversarial control:

```text
ANCIENT MIGRATION TRADITION
!=
SINGLE HISTORICAL MEMORY
```

Use competing ancient traditions as branches rather than selecting one because it best fits a later theory.

Add:

```text
ADV-02 = COMPETING_ANCIENT_MIGRATION_TRADITIONS
```

## Priority 11 — Maeonian -> Lydian ethnonym rebinding

Herodotus says the Lydians were formerly called Meiones/Maeonians and were renamed after Lydus son of Atys.

This is another explicit:

```text
POPULATION-LINE
-> EPONYMIC / POLITICAL RENAMING
```

and should be compared to Herodotus' Briges/Phrygians, Termilae/Lycians, Pelasgian/Athenian/Ionian and Makednon/Dorian chains.

## Priority 12 — Karabel as a monument-reception control

Herodotus 2.106 describes a rock relief on the Sardis-Smyrna road whose equipment he calls both Egyptian and Ethiopian and reports that some viewers identified it as Memnon.

The surviving Karabel relief is now read through Hieroglyphic Luwian as Tarkasnawa, King of Mira.

Thus one western-Anatolian object carries:

~~~
LUWIAN ROYAL MONUMENT
-> GREEK EGYPTIAN/ETHIOPIAN VISUAL CLASSIFICATION
-> MEMNON RECEPTION
~~~

This is a high-value same-object control for how foreign monuments can be reclassified through inherited mythic categories.

The Mira dynastic name Alantalli is added separately as a phoneme probe against the ATL/ATAL/ATAR lattice.
