# HLTG / Crypto-Scribe

Historical Language Transformation Graph: an artifact-first, provenance-preserving comparative research system for ancient languages, scripts, documents, and transmission networks.

## Governing rule

**Raw witness != observation != reading != interpretation != historical claim.**

Do not compare surface words alone. Compare typed historical transformations and ask what survives them.

## Pipeline

`ARTIFACT -> WITNESS -> SURFACE/REGION -> SIGN/TOKEN -> READING -> NORMALIZATION -> INTERPRETATION -> RELATION -> HYPOTHESIS -> TEST`

Crypto-Scribe is the inference/validation layer; HLTG is the canonical knowledge graph; Nexus modules are geographic/contact views; CYP-NEXUS is the first regional implementation.

## Core directories

- `registry/` languages, scripts, nexus zones and controlled vocabularies
- `artifacts/` canonical physical-object records
- `observations/` source-addressed observations independent of interpretation
- `hypotheses/` explicit testable claims, including rejected claims
- `packets/` portable research bundles for Muse/Jethro, other agents, and human collaborators
- `schema/` machine-readable record specifications
- `processors/` Crypto-Scribe/RIIR/formula/topology/null-test integration notes
- `legacy/` provenance map to recovered project assets

## Evidence discipline

Every claim should preserve chronology, geography, carrier/script, provenance, source dependencies, confidence/status, supporting evidence, contradictions, and alternatives. Multiple publications derived from one witness do not count as independent evidence.

Uncertainty is data: `UNKNOWN`, `UNCLASSIFIED`, `CONTESTED`, `HYPOTHESIS`, `REJECTED`, and `INSUFFICIENT_EVIDENCE` are valid states.
