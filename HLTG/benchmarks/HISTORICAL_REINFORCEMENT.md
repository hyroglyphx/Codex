# HLTG Historical Reinforcement Map

This document records project-wide methodological structures recovered from earlier Crypto-Scribe, Ancient Script Lattice, TCIM/ECVR, artifact, and comparative-language work, and relates them to the experimentally tested CYP-NEXUS pipeline.

## Standing inference order

**ADMISSIBILITY -> SCORING -> INFERENCE -> PROMOTION**

Never score a witness that cannot test the hypothesis. Never infer from a score that does not beat appropriate controls. Never promote an inference beyond its evidence class.

The broader executable pipeline is:

`SEAL WITNESS -> ESTABLISH ADDRESS -> TYPE CARRIER -> DECLARE TRANSFORM -> TEST ADMISSIBILITY -> EXTRACT INVARIANT -> PRESERVE RESIDUE -> COMPARE COMPETING MODELS -> RUN NULLS -> REGENERATE ON HOLDOUT -> CORRECT DEPENDENCE -> PROMOTE OR REFUSE`

This operationalizes the older ECVR ordinal: SEAL -> SEPARATE -> EXPAND -> ORDER -> PERMUTE -> PROJECT -> COMPARE -> DISTILL -> REGENERATE -> ASSAY.

## Independence classes

Evidence independence is multidimensional:

- genealogical independence
- physical-witness independence
- scholarly/edition independence
- temporal independence
- transmission/contact independence

CYP-NEXUS provides the explicit temporal control `O_1911 ⟂ H_1914+`: observations frozen before discovery/use of the Amathus bilingual cannot be calibration echoes of bilingual-derived hypotheses.

## Benchmark families

### CYP-NEXUS — Cyprus / Eteocypriot epistemic-control suite
Tests witness integrity, blind known-language calibration, carrier-loss reconstruction, null-model discrimination, partial bilingual equivalence, claim-level separation, scholarly dependency, out-of-sample regeneration, and UNSCORABLE outcomes when the required sign inventory is absent.

Standing bounded result: `a-ri-si-to-no-se <-> Aristona` is retained as a local name-slot correspondence; phonetic equivalence remains weaker, morphology unresolved, genealogy unsupported. The simple `-se = Greek accusative` proposal is preserved as a contradicted adversarial result. Family comparison remains gated pending new evidence.

### ELAM-NEXUS — Elamite / Linear Elamite
Seed material: Sb17 and related inscriptions. Tests bigraphic anchors, name/title regeneration, allography, orientation independence, normalization ladders, and separation of local decipherment support from external etymological comparison.

Key rule: support for an internal normalization/read chain does not promote a separate cross-language resemblance.

### FORMULA-NEXUS — Amarna EA266 / EA292
Tests recovery of a shared formula spine while preserving local residues. Prior benchmark behavior: lower raw identity can normalize to a common formula only through declared transformations; document-specific residues must remain visible.

Rule: **normalize invariant; preserve residue.** Never normalize until texts merely appear identical.

### CARRIER-NEXUS — Linear B inverse reconstruction
Tests forward carrier loss and constrained inverse reconstruction. Candidate reconstructions such as `pa-ta -> panta`, `ka-ko -> khalkos`, and `qa-si-re-u -> gwasileus` are ranked candidates, not automatic identities. Lexicon, morphology, chronology, document type, carrier behavior, and source quality constrain the inverse.

### TCIM-NUMERAL — historical-law vs surface-collision suite
Tests inheritance, parallel-law convergence, borrowing/diffusion, replacement, carrier erosion, analogy, and false-friend collision.

Canonical adversarial control: Turoyo `tre = 2` versus Albanian `tre = 3`. Surface similarity is not genealogy.

The numeral-seven carrier project preserves failures such as Sumerian `imin` rather than excluding them from the model.

### DOCUMENT-GRAMMAR — function before language
Proto-Elamite administrative/livestock material tests whether document function can be recovered when language remains undeciphered. The valid inference layer is the highest layer actually supported by the information present.

### TOPOLOGY-NEXUS — orientation and spatial grammar
Konar Sandal material separates script-designer, scribe, artifact, copy, photographic, and digital reversal states. Text direction is not document topology.

YBC 7289 provides the numerical/geometric control: `VALUE + LOCATION + GEOMETRIC_ROLE -> INTERPRETATION`. Artifact address is therefore generalized beyond linear text to spatial, tabular, radial, network, and geometric documents.

### BILINGUAL-CONTROLS
Controlled bilingual/bigraphic classes:
- Cippi of Melqart: MESSAGE_EQUIVALENT
- Pyrgi Tablets: EVENT_EQUIVALENT
- Tabnit sarcophagus: COLOCATED_NON_EQUIVALENT
- Amathus: PARTIAL_EQUIVALENCE

Rule: same artifact does not imply same event; same event does not imply same proposition; same proposition does not imply same syntax.

### LEGACY-ADVERSARIAL
Earlier exploratory project hypotheses that lacked frozen corpora, declared operators, dependency correction, or null controls should be retained as anti-benchmarks rather than erased.

Purpose: test whether modern Crypto-Scribe refuses promotion of apparently impressive scores when admissibility and controls are absent.

## General rules reinforced across corpora

1. Raw witness != observation != reading != interpretation != historical claim.
2. Function may be recoverable before language; morphology may be unrecoverable even when signs are readable.
3. Carrier continuity does not imply language continuity.
4. Colocation does not imply translation equivalence.
5. Direction/orientation must be grounded independently of the linguistic interpretation it appears to support.
6. Exact-sign, allographic, normalized, phonological, relaxed-historical, and diachronic matches are distinct search levels.
7. Derivative editions and daughter languages do not multiply independent evidence.
8. Nulls and contradictions are first-class results.
9. A detector that performs equally on shuffled controls is non-discriminative.
10. Missing prerequisite features yield UNSCORABLE, not negative evidence.
11. Holdout regeneration outranks retrospective fit.
12. Rejected and bounded hypotheses remain addressable.
13. Numeric/alphanumeric projections are supporting constraints only when the native value system and chronology are independently established.
14. External family comparison opens only after internal structure and admissible constraints are frozen.

## Epistemic-state transition benchmark

Historical project work can itself be represented as a benchmark corpus:

`PROPOSED -> TESTED -> {SUPPORTED, BOUNDED, CONTRADICTED, UNSCORABLE, INSUFFICIENT_EVIDENCE, REJECTED}`

The objective is not a system that always produces an answer. The objective is a system that can reproduce when signal exists, bound a result when portability fails, and refuse promotion when evidence is insufficient.
