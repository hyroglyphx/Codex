What this is. The Book of Soyga (Aldaraia) holds 36 tables, each a 36×36 grid of letters. Two rules behind the tables are verified here: (1) the twelve anagram pairs joining the doubled zodiac tables, and (2) the mod-23 recursive rule that generates every table cell from a six-letter code word. Every check below is computed live in your browser.

The 23-letter alphabet

The tables use the 23-letter Latin alphabet (no J, no V; I stands for I/J, U for U/V). Letters are numbered A = 1 through Z = 23.

Rule 1 — The twelve anagram pairs

Tables 1–12 and 13–24 repeat the zodiac, Aries through Pisces. Each table carries a six-letter code word. The code words pair up as anagrams, strictly by zodiac sign — table 1 with 13, 2 with 14, and so on. No other anagram pairing exists among all 36 words.

Rule 2 — The mod-23 recursive rule

Each table is generated from its code word by one rule, applied cell by cell:

  • First column: the code word, then its reversal, repeated until all 36 rows are filled.
  • First row: start with the code word's first letter; each next letter is X = P + f(P) mod 23, where P is the previous letter.
  • Interior: X = N + f(W) mod 23, where N is the letter above and W is the letter to the left.

Fill order is row by row, left to right, so N and W are always already known. f is Reeds' offset table, recovered from the paper's worked examples and ideal table and verified by regenerating the paper's tables exactly (see verification below).
